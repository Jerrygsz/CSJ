# 炼虚初期卡死 · 诊断与后续主线推进校核

> 触发：玩家「炼虚初期，打到天渊城来客，修为无法静修，无法晋升，后续剧情推不动」。
> 结论：修为引擎有一处写死的上限，把玩家永久钉在 Lv150；另有一颗只授一次却要拿去赌的破境丹。均已修复。

## 一、卡死根因（修为引擎写死 Lv150）

`js/game.js` → `addCultivateXp()`：

```js
while (lv < 150 && guard++ < 400) { ... }   // ← 旧代码
```

- 境界表（`js/maps.js` + `js/lingjie.js` + `js/xianjie.js` 逐段 push）里，上界全在 150 以上：
  **炼虚150 → 合体200 → 大乘260 → 渡劫330 → 真仙420 → 金仙460 → 太乙520 → 大罗580 → 道祖640**。
- 这行 `lv < 150` 让「灌修为」的循环在 150 之后**一次都不跑**：`save.cultivate.xp` 一直涨，`save.cultivate.level` 却永远停在 150。
- 静修 `doRest()` 走的正是 `addCultivateXp()`；战斗结算 `syncCultivate()` 也受同一道大境界门约束。于是玩家到了炼虚初期，**静修一滴不进**（`doRest` 会提示「回进阶页备料冲关」）。
- 而合体关 `breakLevelOk` 要求 **修为 ≥ lv-1 = 199**（炼虚后期·巅峰）；150 ≠ 199，`heti_guan`（天渊城·进阶合体）直接判「修为未达」，连破境演出都不给，`liangzu` 也解不开 —— 整条灵界主线从这里断掉。

复现实测（修复前）：150 级连灌 40 次大额修为 → 等级 **150 → 150**，xp 堆到 39,999,962 仍不升级。

**修复**：`while (lv < 150 …)` → `while (lv < 640 …)`。各道大境界门仍由下方 `breakReqFor(lv+1)` 卡住，不会跳级。

## 二、第二处死锁：万妙丹只授一枚，却要拿去赌三成四

`js/lingjie.js` 合体关（lv 200）：

```js
items: [['heti', 1]],          // 万妙丹
chance: { step: 0.34 },        // ← 旧：一枚三成四
// 且没有 keepOnFail
```

- 万妙丹（`heti`）**只有广寒界（guanghan）授一枚**，`noDrop: true`、`unique`，别处再也拿不到。
- `payBreak()` 每次冲关都会把押进的丹**整颗删掉**；失败（66%）后丹没了、又无第二枚可寻 → 永久卡在炼虚后期。
- 原著里韩立服下这一枚即成，并非赌概率；其它灵界/仙界大境界关（大乘/渡劫/真仙…）也都写的 `chance:{min:1}`。

**修复**：`chance: { step: 0.34 }` → `chance: { min: 1 }`（必成，与其余上界关一致）。
