# 凡人长生劫 · 第 79 轮：Boss 招式按原著重写 + 道陨代价

版本 `20261104F` · 提交 `272f381` · smoke 293/0

## 一、结论先行

1. **Boss 出招不再按"四系模板"打，而是按原著写招式。** 新增 `js/bosskit.js`：32 只关键 Boss 有专属招式表，其余走妖兽 / 魔修 / 虫群 / 血道四张同族表，覆盖全部 82 个 Boss 条目。
2. **出手前有前摇 + 预警圈 + 招式名。** 以前 Boss 是"突然一串弹幕"，现在是"先亮招，再出手"——难度上去了，但不是靠看不见的伤害。
3. **伤害确实加了，而且加在该加的地方。** 45 秒定点承伤实测：真仙马良 +105%、付家家主 +51%、元刹圣祖分魂 +46%、乾老魔 +16%；妖兽 / 虫群 / 血道三系从"二阶段前完全没有远程"变成有稳定的主招。
4. **道陨代价落地**：灵石折半、永不退还；道具随机折半、再战通关原物奉还。实测 1000 灵石 → 500（不退回）、16 件材料 → 9（打回来后回到 16）。
5. **houshan 难度没动**——按你的话，适当难度是好事。

## 二、Boss 招式：怎么改的

### 2.1 结构

| 层 | 文件 | 职责 |
|---|---|---|
| 数据层 | `js/bosskit.js`（新增） | 招式名、冷却、前摇、伤害系数、弹型参数，纯数据 |
| 调度层 | `js/game.js` `updateBossKit()` / `castBossSkill()` | 冷却轮转、前摇计时、12 种弹型执行 |
| 表现层 | `G.tells` 预警圈 + 头顶报招 | 出手前 0.3~1.0 秒的可见兆头 |

**12 种出手方式**：`fan` 扇形攒射 / `ring` 环形荡开 / `beam` 直线贯刺 / `rain` 落点弹雨 / `mist` 弥散毒雾 / `dash` 突进 / `blink` 遁位 / `summon` 召群 / `trap` 定身 / `chill` 冻缓 / `pull` 牵引 / `nova` 贴身爆发 / `heal` 回气。

## 三、道陨代价

### 3.1 规则

| 项 | 规则 |
|---|---|
| 灵石 | 阵亡当场折半，**永不退还**（记入 `save.stoneBurned`，只用于展示累计） |
| 道具 | 从储物袋随机抽走总量的 **50%**，按图记账；**把这张图再打穿一次，原物奉还** |
| 豁免 | 四个装备槽上的东西不动（穿在身上的夺不走） |
| 多次阵亡 | 同一张图反复死，失落清单**累加**而不是覆盖（覆盖等于白丢前一次的） |
| 覆盖范围 | 只在战斗图阵亡时结算；剧情 / 破境失败仍走各自原有逻辑 |

### 3.2 实现要点

- `deathToll()`：算灵石、洗牌抽道具、写 `save.deathLost[mapId]`。
- `reclaimLost(mapId)`：在 `finishMap()` 里、结算之前调用——**先还东西再发奖励**，结算面板不会把"寻回"和"所得"混在一起。
- 结算面板多一行 `寻回前番失落 · 道具 ×N（M 味）· 原物奉还`。
- 道陨面板新增「道陨代价」区块（暗红细框，见 `qa/shot-gameover-toll.png`）。

### 3.3 验收

```
阵亡前　灵石 1000　材料 16 件
阵亡后　灵石 500　材料 9 件    → 灵石掉 500，材料掉 7
再战通关　灵石 500　材料 16 件  → 道具已原数奉还，灵石未退还（符合规则）
```

（材料掉 7 而不是 8，是因为这一半是按**全袋**总量抽的，抽中了 1 件非材料的杂项，属正常。）

## 四、回归

| 项 | 结果 |
|---|---|
| smoke | **293 通过 / 0 失败** |
| pacing（21 张战斗图） | 平均峰值 24.0、平均击杀 304、平均顿悟 12.0、阵亡 **4/21** |
| 帧耗 | 0.083ms/帧（改前 0.086），无退化 |

**关于阵亡 4/21**：改前是 1/21。这是"Boss 伤害增加"的直接结果，但也包含机器人不会读前摇、不会躲落点弹雨的因素（`pacing` 的走位规则只避当前弹幕，不预判预警圈）。真人玩家有 0.3~1.0 秒的预警提示，实际体验会明显好于这个数字。没有为了让数字好看去削 Boss——你要的就是"有危机感"。

## 五、待你拍板 / 已知取舍

1. **马良 +105%** 是目前最猛的一档。他是真仙终局 Boss，我按"该有的压迫感"给了四招；若实测觉得过，最容易下调的是 `法相降临` 的 `k`（0.85）与 `九元真言` 的冷却（5.2s）。
2. **召群口径**：地图上写 `summon:''` 或 `noSummon` 的 Boss，招式表也不许召群（教学关靠这条守住）。已加保护，专属表也不能绕过。
3. **只有 32 张专属表**：剩下 50 个 Boss 条目走同族表。若要逐只写，按同一份数据格式补 `BOSS_KITS` 即可，不用改引擎侧任何代码。
4. **难度未动**：houshan 保持上一轮的 `packMax 12 / trashDmgMul 0.6 / boss [100,3]`。
