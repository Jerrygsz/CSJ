> 由 `qa/dump-stats.mjs` 从运行中的游戏直接抽取（`REALM_LAYERS` / `ENEMY_TYPES` / `MAPS` / `ENCOUNTERS` / `BREAKTHROUGH` / `CAVES`），

统计口径：

- 经验：升级到下一层所需 = `floor(5 + Lv×2.6 + Lv²×0.14)`；累计 = 1 级到该层之和。
- 主角气血：`100 + 各境界层 hp 累加 + 装备/被动/传承加成`。
- 境界加成：每跨过一层，`dmg`（伤害倍率）、`atk`（攻速倒数加成）、`spd`（移速）**累加**。
- 敌人数值为「图内基础值」，进入战斗后还要乘地图 `diff`（难度系数）与难度档（凡境 ×1 / 险境 ×1.75 / 死境 ×3.1 血）。

## 二、主角属性构成

| 项 | 基础 | 成长来源 |
|---|---:|---|
| 气血上限 | 100 | 各境界层 hp 累加（见上表）+ 装备/被动/传承/丹药永久加成 |
| 伤害 | 100% | 境界层 dmg 累加 + 装备/功法/被动/丹药 |
| 攻击间隔 | 1 / (1 + 攻速加成) | 境界层 atk 累加 + 攻速类装备与符箓 |
| 移速 | 基础值 × (1 + spd 累加) | 境界层 spd + 鞋子/身法 |
