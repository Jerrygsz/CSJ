# 凡人修仙传·人界 —— 按境界的功法 / 装备 / 材料 / 丹药：小说原型与游戏落地设计

> 目的：把《凡人修仙传》人界五境（练气 → 筑基 → 结丹 → 元婴 → 化神）里，**韩立在各境界真正能用上的功法、装备、材料、丹药**一条条从原著里摘出来，并给出"在战斗 / 修炼里怎么用"的属性方案与获取方式。
> 现状对照：✅ 已在游戏内 ／ ➕ 待补 ／ 🔧 需改造（现为被动物品，未接入功法系统）。

---

## 〇、人界境界表（用户给定，游戏已按此建模）

| 大境界 | 小境界 | 说明 | 游戏对应 |
|---|---|---|---|
| 炼气期 | 1～13 层 | 引气入体，凡人起步 | `REALM_LAYERS` 13 层，每层 +生命/伤害/攻速/移速 |
| 筑基期 | 初→中→后→大圆满 | 灵气液化 | `lv 36` 起 |
| 结丹期 | 初→中→后→大圆满 | 凝结金丹 | `lv 56` 起 |
| 元婴期 | 初→中→后→大圆满 | 金丹化婴，可夺舍 | `lv 82` 起 |
| 化神期 | 初→中→后→大圆满 | 渡雷劫，飞升 | `lv 112` 起 |

**核心机制约定（落地规则）**
- **近战 / 远程**：给每门功法打 `type` 标 —— `melee`(贴身)、`aura`(环绕)、`ranged`(弹道)、`ranged_aoe`(爆发/追踪)、`passive`(被动)。
- **消耗**：丹药 / 符箓 / 灵液三类是"即用即耗"，快捷栏点一下就少一个（游戏 `useQuick` 已做扣减，需保全路径）。功法本身不耗，靠修炼升层。
- **大境界突破**：旧功法自动卸下，只留 1 门主力（`trimSkillsToMain` 已实现，跨筑基/结丹/元婴/化神触发）。✅
- **获取三途**：打怪/杀人掉"法诀"、剧情地图奖励给、坊市买。
- **学 & 练**：每门"法诀"学一次得 1 层；之后靠升级三选一、境界突破、杀敌熟练度往上练。

## 六、战斗落地机制（data-driven 改造方案）

**问题**：现在 `fireWeapons()` 把 sword/fire/nova 写死在代码里，新功法无法自动开火；`type`（近战/远程）没有字段；高境功法（青元剑诀/大衍诀/元磁神光…）是"被动物品"而非 SKILLS，不进功法系统。

**方案**：给 `SKILLS` 每条加属性字段，战斗读字段而非写死 ID：
```
{ id, name, icon, minLv, max, main, type,
  // 攻击型：
  dmg, cd, range, pierce, aoeR, home(是否追踪), count(弹数),
  // 被动型：
  effect(回血/移速/攻速/拾取/暴击…) }
```
- `type` 决定渲染与手感：`melee`(贴身挥砍) / `aura`(环绕) / `ranged`(定向弹) / `ranged_aoe`(爆发) / `passive`(常驻)。
- 把 `qingyuan/dayan/yuanci/dayan2/t_pojie` 等"功法类被动物品"**迁移成 SKILLS**（保留其 effect 作被动加成），接入：学（法诀/剧情）、装（洞府）、突破留 1 主力、练层（三选一/突破/杀敌）。
- 进攻型新功法（血魔剑诀/三焰扇/辟邪神雷/惊神刺）按 `type`+`dmg`+`cd` 接入发射循环，真正在战斗里开火。
