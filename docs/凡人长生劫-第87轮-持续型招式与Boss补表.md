## 一、持续型招式：三种，都是真判定

上一轮做的 `G.zones`（困阵 / 冰面 / 漩涡）明确只做「看得见的范围 + 减速」，一伤害也不结算 —— 那是刻意的，加视觉不该顺手改难度。

这一轮另开一套 `G.hazards`，它们**真的每 tick 扣血**。两套的分工写进了代码注释，避免以后有人把两者混用。

### 1.1 三种招式的判定口径

| 招式 | 判定形状 | 结算方式 | 参数口径 |
|---|---|---|---|
| `pillar` 光柱 | 圆（半径 44~52） | 每 `tick` 0.40s 结算一次，站里面就一直掉 | `k` = **每 tick** 系数，0.29~0.33 |
| `sweep` 横扫光刃 | **线段**（`distToSeg`），宽 14~17 | 同上，每 0.45s 一次；但刃扫过一个人只需约 0.19s，实际最多命中 1 次 | `k` = 单次系数，0.48~0.54 |
| `spike` 地刺 | 一串圆点（每点半径 26~28） | **每个点位只结算一次**，破土瞬间没踩上就作废 | `k` = 单次系数，0.55~0.58 |

横扫特意用线段而不是圆去比：用圆去比，贴着刃边站的玩家会被漏判 —— 玩家会看到「光刃明明从我身上划过去，却没掉血」。

### 1.2 为什么不会秒人（三道闸）

1. **起手有预警圈**，`tele` 0.66~0.86s，和上一轮所有招式同一套节奏；
2. **tick ≥ 0.4s，而玩家自带 0.55s 无敌帧**，所以站在光柱里最多 1.8 下/秒；
3. **单跳系数只给 0.29~0.33**。

实测（同一张图、同一只 Boss、站定不动）：

```
pillar 光柱：命中 3 次 · 每次 4% 气血 · 站稳整根 1.7s 共 12% · 结束后残留 0
sweep  横扫：命中 1 次 · 4% 气血（这条测试用的是 k=0.31，正式表里已提到 0.48~0.54）
spike  地刺：命中 1 次 · 7% 气血 · 结束后残留 0
```

**「站在里面」整段约 12% 气血，走出来只挨第一下 4%。** 这个比例是有意的：它够疼，值得为它挪一步，但不至于「没反应过来就死了」。

### 1.3 走出去必须立刻停手

`tickT` 在离开范围时归零重算（再进来立刻挨一下，符合直觉）。实测：

```
站光柱里 1.1s：1 下 / 4% 气血
挪到 320px 外 1.1s：0 下 / 0%
```

外圈是干净的 0 —— 这点必须验，否则「有范围」的招式就退化成全屏伤害。

### 1.4 预警圈画在落点，不画在 Boss 脚下

定桩招（光柱/地刺）的落点是**前摇开始那一刻玩家站的地方**。所以预警圈必须画在落点：

- 画在 Boss 脚下 → 玩家看到脚下亮了一圈，但不知道该躲哪儿，这一招就变成纯运气；
- 画在落点 → 玩家看得见「这块地要炸了」，挪一步就能躲，**这一招才成立**。

顺带一个真实战斗里出现的好例子：血云·血祭大阵会先用「血祭吸元」把玩家拽开，再落「血柱冲天」—— 玩家如果正被拽着，柱子的落点是拽之前的位置，会打空。这是机制自然咬合出来的，不是我特意设计的。

### 1.5 联机：队友也得掉血

光柱/地刺/横扫对队友同样结算（走 `Coop.addPartnerHurt`）。否则双人里总有一个可以站进光柱里白嫖 —— 那这条机制在联机下等于不存在。

## 二、48 只 Boss 的专属招式表

### 2.1 派发原则

原著里这 48 只多数只有名号、没有具体战况描写。硬编三招等于我自己写小说，所以按「出处 → 门派/种族 → 修为层次」三级取证：

- **有明确功法出处的按出处写**：冰凤的寒气、矿脉磁光兽的磁光、白光界土皇钉的戊土、佛骨王的骨、太乙境噬金仙的噬金、萧晋寒的天庭敕令；
- **只有名号的按身份写**：傀儡就是机关（地钉 + 巨鼎 + 机关臂），阵灵就是阵（血柱 + 血雾 + 牵引），道祖就是法域；
- **新招式的派发也跟着属性走**：柱 = 光/火/佛/雷；刃 = 剑修/刀修/大能；刺 = 土/骨/金/木/冰。

这条「属性 → 形体」的对应关系和上一轮定下的「形由招式语义决定」是同一条纪律，只是这次多了三种形体可选。

### 2.2 低阶区间刻意不给持续招

山贼头目（lv1）、贾天龙（lv13）只给「刀法 + 冲撞」。1 级新手关放一根光柱，等于把人劝退 —— 持续型招式从 lv52 的七级妖兽才开始出现。

## 三、渲染：三个踩到的坑

这一节的教训比结论有用，写清楚免得下次再踩。

### 3.1 CanvasGradient 的颜色节点绕过了砍色拦截

水墨皮的砍色规则是靠**拦截 `ctx.fillStyle` 的 setter** 实现的。但 `createLinearGradient(...).addColorStop()` 里的颜色是**在那一刻就定死的死值**，根本不经过 setter。

结果：第一版水墨皮下，光柱和光刃全是鲜艳橙色 —— 因为它们的颜色全在渐变里。

**改法**：渐变的每一个 stop 显式过一遍 `inkify()`。这条以后凡是新写渐变都要记。

### 3.2 光柱不能用「实色填充 + globalAlpha 整体压」

第一版是「一个梯形路径填实色，再用 `globalAlpha` 统一压到 0.16」。看起来对，但梯形路径的**顶边永远是一条硬横线** —— 那不是光该有的收束，是几何边缘。

**改法**：用带 alpha 的渐变色一次铺满，让它真的淡到 0。侧界线也要走渐变描边，否则柱子两侧就是两根竖到底的「轨道」。

### 3.3 地刺不能往顶部渐隐

第一版用地刺从实色渐隐到透明，刺尖化成了一缕白烟 —— 看着是光点，不像石头从地里戳出来。

**改法**：实心填充 + 左半受光面 + 一条从尖到底的棱线 + 落地阴影。立体感靠「受光面 / 暗面」两块拼，不靠透明度。

顺带：横扫的「动感」也不能靠再画一条错开 0.075rad 的刀 —— 440px 外那是 33px 的错位，画面上就是两根并排的杆。改成同一把刃在 0.058rad 内连画六层、alpha 用「保底 + 上浮」而不是纯幂次（纯幂次会让中间几层几乎为 0，层间露缝）。

## 五、明确没做的

1. **持续光柱没有「扫射」版本**（会旋转的光柱）。横扫光刃已经承担了「移动的持续判定」，再加一个同类只是换皮。
2. **地刺不做地形阻挡**。它能伤人但不能封路 —— 封路要接寻路与碰撞，会牵动整个移动系统。
3. **没有给每个点位单独的音效**，整招共用一次 `Sfx.warn()`。多段音效需要新的音源文件。
4. **柱高固定 200px**，没有按 Boss 体型缩放。体型差异大的 Boss（傀儡 vs 道祖）看起来高度一样，这一点可以再调。

## 六、下一步建议

按性价比排：

1. **给持续招式加「离场引导」**：光柱落地前 0.2s 在地面先亮一道裂缝，比只有预警圈更能说清「从这儿出来」。
2. **柱高/柱宽跟 Boss 体型挂钩**：`sk.h` 已经支持，只是没填。
3. **27 只之外的持续型机制**：真正的全屏冲击波（需要新的屏幕空间判定）—— 但这会动平衡，得单独一轮。
