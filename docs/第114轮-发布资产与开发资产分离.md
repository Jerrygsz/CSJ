# 第114轮 · 发布资产与开发资产分离（2026-11-06）

## 一、问题：仓库里混了两套东西，而且全都被公开

Jerry 问「是否把网页必需的文件与不必放 GitHub 的文件混在一起了」。查下来是，而且比想象中严重。

**机制**：本仓库没有 `.nojekyll` / `_config.yml` / Pages workflow，GitHub Pages 是**直接从 `main` 根目录整棵发布**。仓库里每一个非下划线开头的跟踪文件都能被公网直接访问。HEAD 请求实证：

| 线上路径 | 结果 |
|---|---|
| `/CSJ/raw/凡人修仙传.txt` | `200`，`Content-Length: 22,545,916`，`text/plain` |
| `/CSJ/qa/shot-final-boss.png` | `200`，1.67 MB |
| `/CSJ/codex/mapCodex.json` | `200`，590 KB |

而网页真正会请求的只有 **30 个资源 / 1.86 MB**（`index.html` 里带 `?v=20261106S` 的 29 个 JS + 1 个 CSS），加上 CSS 引用的 `assets/guigu/beast-lang.png`（2.67 MB）与 `sw.js`，**必需总量约 4.5 MB**。

仓库实际：**914 个文件 / 246.11 MB**，其中 `qa/` 占 718 个 / 199.9 MB（450 张 png），`raw/` 占 35.6 MB（含两本原著全文）。

**最要紧的一条**：两本《凡人修仙传》全文（22.7 MB + 13.9 MB）由 10-27 的 `ad3d000` / `c7c24d5` 提交入库，是受版权保护的整本小说，在公开 Pages 上可直接下载。

### 第二步 · 治本（提交 `a8ac977`）

**`scripts/build-site.mjs` — 不手写文件清单。**

沿用第113轮的教训（「闸门不能复刻实现，只能读实现的产物」）：从 `index.html` 的 `src/href`、`serviceWorker.register()`、CSS 的 `url()` **反推**网页真正加载的资源。以后加个 JS、换张图，只要改引用，发布清单自动跟上。

内置三道断言，任一不过即非零退出：
1. 引用的文件不存在；
2. 清单里混入 `qa|codex|raw|docs|tools|canon|vendor|.github` 等开发资产或 `.txt`；
3. 超过 60 个文件 / 10 MB。

解析细节：内联 `data:` URI 要整体剥离——本项目 CSS 的 SVG 噪点滤镜里含 `url(%23p)`（URI 内部的片段引用），首跑就被闸门抓出来报 `css/%23p`，剥离后正常。产物 **32 个文件 + `.nojekyll` = 4.43 MB**。

**`.github/workflows/pages.yml`**：`push main` 且仅运行文件路径变更时，构建 `_site/` 并以单提交覆盖 `gh-pages` 分支。`paths` 过滤让只改文档 / 闸门 / 考据时不触发发布。`main` 的历史、内容与现有开发流程都不动。

**发布源切换**：用 GitHub Pages API 把 `source` 从 `main / root` 改为 `gh-pages / root`。

> **坑（记下来）**：改完 API 回读已是 `gh-pages / root`、`status: built`，但线上 `codex/` / `qa/` / `docs/` / `package.json` 仍是 `200` —— 因为**改 Source 本身不触发重建**，最近一次构建仍是 `commit=a8ac977`（main）。必须再 `POST /repos/{owner}/{repo}/pages/builds` 请求一次构建；重建后构建记录的 commit 变成 `726b09b`（gh-pages），开发资产才全部 404。
> 以后 workflow 每次 push 到 `gh-pages` 会自动触发构建，不用手动。

## 五、经验

1. **「仓库」和「发布目录」是两个概念**。Pages 默认整棵发布分支，把考据真源、闸门脚本、内部文档和版权素材一起推上公网，直到被问起才被发现。
2. **清单必须从产物反推，不能手写、更不能复刻实现**——与第113轮同源。手写清单早晚会和 `index.html` 失同步。
3. **删文件前先复制 + 全量哈希校验**，确认副本完好再动源；443 个文件、228 MB 零丢失。
4. **改 Pages Source 不等于重新构建**，切完必须核对构建记录的 commit 与线上 404，否则会误判「已生效」。
5. 本机 HTTPS push/fetch 会撞 `schannel: server closed abruptly`；**SSH remote 可直推**，本轮用它绕开。
