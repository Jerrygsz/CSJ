# 凡人长生劫 · 功法攻击效果设计

> 本文档对应代码实现：`js/skills.js`（`atk.vfx` 字段）与 `js/game.js`（弹道/领域/环绕/天雷/命中特效分支）。
> 设计目标：让每一门功法在「不增加任何美术素材」的前提下，拥有独立、可辨识、且贴合《凡人修仙传》原著气质的攻击表现。
> 守门脚本：`qa/verify-skillfx.mjs`（52 项断言全部通过）。

---

## 一、设计原则

1. **零素材，全靠画。** 角色与怪物只有程序化网格，没有逐帧特效用图。所有攻击特效都用 Canvas 2D 即时绘制（光刃、火蛇、雷网、冰晶、重力波纹……），不引入任何 PNG/序列帧。
2. **一门功法一套表现。** 早期所有功法命中都是同一个白方块、所有弹都是同一把剑的贴图，打谁都一样。现在每门功法有：独立的弹道外观 + 独立的命中颜色 +（部分）独立的爆发/领域/环绕形态。
3. **命中颜色即门派。** 光看溅射颜色就能判断是哪门功法打中的，不必读飘字。`VFX_HIT_COLOR` 集中管理这套配色。
4. **魔道要有「克」的感觉。** 辟邪神雷是原著招牌，必须做出「对魔道妖物额外凶狠」的机制，而不是换个颜色而已。
5. **紧贴原著，不自己编。** 特效的视觉语言（青碧剑芒、火蛇追踪、金雷、血煞、三色异火、元磁重力）均取自小说原版设定，不凭空捏造。

## 三、逐项设计

### 1. 青元剑芒 / 控物术（`qingmang`）
- **弹道**：青碧色细长光刃（`rgba(120,240,196,0.9)`）+ 一道白色亮芯（`rgba(235,255,247,0.95)`），身后拖一道青碧尾迹（`rgba(90,230,180,0.75)`）。形如飞剑破空。
- **爆发变体**：`novaBlast` 在 `qingmang` 下扩张环改用青碧 `#9df0d0`，与默认金色区分。
- **原著**：青元剑诀是韩立的本命剑诀，剑芒青碧、可分光化剑、御剑取人首级于千里之外。青碧剑气是它在书里最标志性的视觉。

### 2. 火弹术（`snake`）
- **弹道**：8 段蛇身按时间相位左右扭动，从尾到头由粗到细；三层描边——外焰暗红（`rgba(190,60,20,0.34)`，宽 11）、蛇身橙（`rgba(255,140,55,0.95)`，宽 5.2）、亮芯（`rgba(255,224,150,0.85)`，宽 2）；蛇头橙黄（`#ffb347`）带白芯。
- **弹道类型**：`homing`（自动追踪敌人），呼应「放出火蛇自己追着人烧」。
- **原著**：火弹术是韩立早期最常使用的符箓之一，符成之后化火蛇窜出，自动锁定目标焚烧，是低成本高机动的代表手段。

### 3. 金光罩（`gang`）
- **环绕**：金青色气团（`#dfefc0`）外裹一圈细光（`#eaf6d0`），以 `orbAng += dt*2.4` 绕玩家旋转，贴身才造成伤害（真·近战领域）。
- **原著**：玄罡之气护体，罡气如环环绕周身，既御敌又示警。金青配色取自「罡气」的质感，区别于法术金光。

### 4. 定神符 / 惊神刺（`gold`）
- **爆发**：`novaBlast` 在 `gold` 下——一道金色扩张环（`#ffe98a`）之外，再放射 12 道金白光条（`ray`，`#fff6c8` / `#ffd76a`），像光从身上炸开。
- **原著**：定神符放金光伤敌护身；惊神刺以琴音化金光波纹，扫荡一片。两者都是「金光爆开」的观感，故共用一套表现。

### 5. 冰冻术（`ice`）
- **领域**：脚下一片冷色径向渐变地盘（蓝白）+ 内圈冷雾 + 边缘 10 片缓慢旋转的冰晶（`#e2f8ff`）；踏入者被拖慢（减速 0.45）。
- **原著**：冰冻术放寒气冻敌，踏入寒域者动作迟缓。冷蓝而非纯白，避免「像套了个气泡」。

### 6. 血魔剑诀（`blood`）
- **弹道**：通红剑芒（`rgba(235,52,72,0.95)`）+ 白芯（`rgba(255,190,190,0.9)`），外裹一层脉动暗红血雾（`#7a0f1e`，随时间 `sin` 呼吸），红拖尾（`rgba(255,60,80,0.7)`）。
- **门派**：魔道功法（boss `kind:'blood'` / `kind:'mo'`）。
- **原著**：血魔剑诀、血道一脉以血光煞气伤人、吞噬精血。血红 + 血雾的「吞吸感」直接对应小说里血魔功法的阴戾气质。

### 7. 三焰扇（`fan`）
- **弹道**：三发扇形扇出（`spread: 0.5`），每发是三色火轮——赤（`#ff4a2e`/金芯 `#ffd05a`）、橙（`#ff9a2e`/淡 `#fff0b0`）、紫（`#a45cff`/淡 `#e6ccff`），越靠里越亮。
- **原著**：三焰扇（妖修/魔道一脉法宝）一扇出三色异火，颜色驳杂而炽烈，对应这里的「三色火轮」。

### 8. 辟邪神雷（`thunder`）
- **天雷**：自天而降的金白折线雷，三层描边——外围金辉（`rgba(255,200,90,0.55)`）、冷白（`#fff3c8`）、亮芯（`#ffffff`）；落点一道短光柱（`#ffe9a8`）+ 两圈金白冲击环 + 10 粒火星。
- **雷网**：落点生成 `web` 粒子（金白电网，`#ffe9a8`）。
- **克魔机制（核心）**：
  - `isEvil(e)` 判定魔道：`kind==='mo'` / `kind==='blood'` / `spr==='mo'` / `evil===true`。
  - 命中魔道时：雷网更密（3 段 vs 普通 2 段）+ **伤害 ×1.6**（`thunderStrike` 内 `evil ? dmg*1.6 : dmg`）。
  - 普通敌人：基础 2 段雷网、无加伤。
- **原著**：辟邪神雷由金雷竹炼制，是韩立压箱底的招牌手段，专破魔道妖物，金白色雷光、威力奇大。这里的「金白雷 + 对魔道额外加伤」正是把这一招牌机制落进了战斗数值与表现。

### 9. 元磁神光（`gravity`）
- **领域**：三圈向外扩散的紫色重力波纹（`#b49cff`，随相位 `ph` 扩张并淡出）+ 一层淡紫填充（`#6a4fd0`）；踏入者被强力拖慢（减速 0.5）。
- **配色纠正**：早期重力波纹误用蓝色，已改为紫（`#b49cff`），与冰域冷蓝区分，也更符合「元磁」的异力质感。
- **原著**：元磁神光出自元磁山神通，以重力禁锢敌人、吸摄金属法宝。一圈圈「压下来」的波纹直观传达「重力」，紫色异于水系冰蓝。

## 四、技术接线

- **数据层**：`js/skills.js` 每门功法的 `atk` 对象新增 `vfx` 字段（如 `vfx: 'qingmang'`）。`fireActive()` 按 `a.vfx` 分发给对应的弹道/领域/环绕/天雷分支；缺省回退到 `'sword'` 贴图（防止字段写错时「所有功法长得一样」）。
- **着色层**：`VFX_HIT_COLOR` 集中管理各门派命中色；`gravity/gang/thunder` 三色明确非蓝。
- **克魔层**：`isEvil(e)` + `spawnWeb(x,y,rad,color,evil)` + `thunderStrike(x,y,dmg,target)` 三件套实现辟邪神雷的「雷网加密 + 伤害 ×1.6」。
- **粒子层**：`web` 粒子是纯视觉（不走物理位移），在 `updateParts` 循环中以 `!p.web` 排除位移，由 `drawPart` 的 `pt.web` 分支绘制金白折线电网。

## 五、验证

- `qa/verify-skillfx.mjs`：**52 通过 / 0 失败**，覆盖——
  1. `skills.js` 各功法 `vfx` 字段接线正确；
  2. `drawBulletVfx` / `drawField` / `drawOrb` 各分支存在且未被重构漏掉；
  3. `thunderStrike` 克魔（魔道多段雷网、伤害正好 ×1.6、三类魔道敌均触发）；
  4. `drawBolt` 已去蓝改金白；
  5. `VFX_HIT_COLOR` 重力/玄罡/神雷三色不回退成蓝；
  6. 运行时克魔对 boss(mo/blood)、mob(mo) 均生效，正常敌人无加伤。

- 回归：`verify-anim` 113/0、`smoke` 288/0、`verify-part4` 80/0、`verify-quickbar` 27/0、`verify-prefight` 26/0，VFX 改动无回归。
