# 第119轮 · 同伴 / 灵宠遇险侧身（不站桩）

## 一、需求

> 「同伴灵宠虽然是自由走动，但是行为模式是在遇到攻击或碰撞时会运用类似韩立使用大衍挂机自动躲避的方式，只是不站桩而已。」

第118轮把随行者从「跟随炮台」改成了可视范围内自主找怪打，但挨打只会走 `hurtAlly()` 掉血 + 0.55s 无敌帧，没有任何规避动作。本轮补上「遇险会躲」，同时**保留第118轮的自由 AI**：平时照旧自己找怪、近身贴 30px / 远程拉 132px、不出 `G.cam` 起的 `W×H` 矩形；只有真要撞上了才让半步，让完立刻接着打。

## 二、主角那套「大衍挂机」到底怎么躲

只读排查 `js/game.js` 的 `5767` 起「自动战斗（站桩挂机）」段：

| 常量 / 函数 | 值 / 作用 |
| --- | --- |
| `DODGE_DIRS` | `12`，顺时针试 12 个方向（含原地不动） |
| `DODGE_STEP` | `0.18` 秒探半步，不是逃 |
| `DODGE_T` | `[0.1, 0.24, 0.4]`，按三个时间点预测威胁位置 |
| `DODGE_NEAR` | `140`，小怪只在这个半径内算威胁 |
| `DODGE_NEAREST` | `22`，虫群图只留最近 22 条威胁 |
| `autoThreats(p)` | 收集 `G.ebullets`（w=1）、`G.enemies`（w=0.55，带朝人走的预测速度）、`G.boss` 冲刺（w=1.2） |
| `autoDodgeDir(p)` | 对每个候选位置按 `k2*k2*w` 打分，挑比原地好 `>0.02` 的最不疼方向；上一帧方向给 `0.08` 惯性，免得两帧一换原地抖 |
| `autoAnchor` / `DODGE_HOME*` | **站桩专属**：躲完把人拉回开自动时脚下那一块 |

主循环 `G.autoOn` 时把 `autoDodgeDir(p)` 直接当移动输入，所以开自动后人是「脚下生根，遇险侧身」。

## 三、随行者版本：同口径，删掉锚点

`allyThreats(e)` / `allyDodgeDir(e, th)` 复用**同一批常量**（不是另抄一份数字），`allyMove()` 里在自由 AI 之前先算一次：

```js
const th = allyThreats(e);
const dv = allyDodgeDir(e, th);
if (dv) { e.dodgePrev = dv; e.dodgeT = ALLY_DODGE_HOLD; e.dodging = true; }
else if (e.dodgeT > 0) { e.dodgeT -= dt; e.dodging = ...; }  // 顺着原方向再走一小段
else { e.dodging = false; e.dodgePrev = null; }
```

四处刻意的不同，都是为了让「不站桩」成立：

1. **没有 `autoAnchor` / `DODGE_HOME*`**：`score()` 里删掉归位拉力。挂机躲完要回桩，随行者躲完直接回 `allyTarget()` 的自由 AI。
2. **`ALLY_DODGE_HOLD = 0.28`**：威胁消失后顺着刚才的方向再走 0.28s，避免每帧重新打分导致原地抖；惯性走完立刻交还自由 AI。
3. **贴身怪的预警圈收紧**：主角是 `en.r + p.r + 14, w=0.55`，随行者改成 `en.r + e.r + 4, w=0.32`，并跳过 `en._dead`。主角站桩不怕被推开，近身型随行者却要贴到 30px 才能出「近身」功法 —— 照抄主角那圈会把自己的目标一直推远，永远打不到。
4. **速度同 `allyMove`**：`(G.player.spd || 130) * 0.92`，不额外加移速，躲避不变成瞬移。

弹幕、Boss 冲刺的权重与预测口径与主角一致。躲不掉（12 个方向都不比原地好）时返回 `null`，按原来自由 AI 继续，不会被围住时卡死。

**躲避 ≠ 无敌**：第118轮的 `hurtAlly()` / 血量 = 韩立满血 50% / 十息复活 / 欠费必须洞府交钱，一律不动；真被命中照样掉血、照样会殒落。闸门专门验了这一条。

## 五、闸门怎么钉住「不站桩」

O 组用真实页面探针造一发正对随行者的高速弹幕，逐项验：

- 干净场面 `threats=0 / dodging=false / dir=null`（不乱躲）
- 弹幕逼近 `threats>0 / dodging=true / dir` 非空，且方向以横向为主（侧身让，不是顺着弹幕跑）
- 连续推进后位移 `> 6px`（真挪窝）
- 清掉威胁、惯性走完后 `dodging=false` 且继续移动（回到自由 AI，没站桩）
- 直接 `allyHurt(id, 20)` 仍掉血（不是无敌）
- 贴到视野角上再给威胁，位置仍被夹在可视矩形里
- 源码断言：`allyDodgeDir` 直接引用 `DODGE_DIRS / DODGE_T / DODGE_STEP / DODGE_NEAR / DODGE_NEAREST`；代码行里没有 `G.autoAnchor / DODGE_HOME_W / homeD`；威胁来源含 `G.ebullets / G.enemies / G.boss`；`allyMove` 里 `allyDodgeDir / allyTarget / allyClampView` 三者并存。

P 组喂 10 份坏数据给同一个 `validateR119()`：偷偷加锚点、方向数改 4、时间点改单帧、干净场面乱躲、逼近不触发、顺着弹幕跑、要躲没挪窝、躲完站桩、变无敌、贴边出界 —— 全部必须被拦下。

> 一处断言返工：最初用 `!/autoAnchor|DODGE_HOME/.test(dodgeSrc)` 判「没有锚点」，被注释里「唯一删掉的是 autoAnchor 的归位拉力」这句话误伤。改成先剥掉整行注释再看代码行，只查真实标识符。
