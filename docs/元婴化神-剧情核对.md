## 三、剧情杀（该跑就跑，该残就残）

三处严格按原著做成了「打不过」：

1. **黄龙山大战（追逃）** — 仲神师是化神修士，元婴初期打不得。这张图没有 Boss，只有强敌，撑过 95 息自动结算「全身而退」。
2. **慕兰草原（追逃 + 封印）** — 几个元婴法士围殴，打赢原著里也没赢。撑过 90 息结算，但代价是**五鬼锁魂**：修为只剩四成、气血减半、**人也是灰的**，直到大晋佛宗用金刚舍利镇煞才解开。
3. **坠魔谷（血焰主魂）** — Boss 血量 24000，正常打不过就跑；打赢了也会被空间裂缝卷进灵渺园（剧情接闭关 27 年）。

追逃图的机制：`type: 'chase'` + `escapeAt` 秒数。时间到自动清场、结算、播收尾对白。它奖励的是「活着」，不是「杀人」。

## 四、新系统

### 换装立绘
袍色随境界（练气绿 → 筑基青 → 结丹月白 → 元婴紫金 → 化神玄金），**护甲优先**——穿了什么甲，身上就是什么颜色。粗布道袍、鹿皮软甲、软猬甲、寒玉甲、玄龟甲、云纹法衣、血魔甲、蛟龙甲、天蚕衣各有一套配色。被封印时人是灰的。

### 技能境界限制
- 每门功法有 `minLv`（不到境界连门都入不了）
- 等级按境界封顶：练气 3、筑基 4、结丹 5、元婴 6、化神 7
- 地图 `startSkills` 给的起手功法同样受封顶——不能因为在高级图里就凭空修到高阶

### 灵宠（养宠）
六只，全部按原著来：

| 灵宠 | 来源 | 原著依据 |
|---|---|---|
| 啼魂兽 | 阴冥之地 | 鬼雾里捡的小兽，叫声震散阴魂 |
| 噬金虫 | （既有的噬金虫袋） | 海猿岛偶得 |
| 六翼霜蚣 | 付家支线 | 218 岁收的 |
| 银月 | 银月认主 | 虚天鼎器灵 |
| 元婴后期傀儡 | 极西之地 | 大衍神君毕生心血 |
| 冰凤 | 小极宫 | 十级冰凤，打不过才肯跟着 |

洞府新增「灵宠」页，放一只随行。战斗中它跟在身后半步，自己索敌出手（伤害比主人轻，胜在不停）。灵宠与「只此一件」的法宝分开——宠物是活物，不在物品掉落池里。

### 洞府三处
落云宗洞府（98 级封顶）→ 大晋佛宗别院（112）→ 坠魔谷芥子空间（140）。
