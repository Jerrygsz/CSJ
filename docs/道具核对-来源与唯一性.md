# 道具来源核对 · 与唯一性规则

按《凡人修仙传》原著逐件核对：**这件东西是怎么到韩立手上的**，以及**它在这世上是不是只有一份**。

判定口径：
- **剧情所得** — 别人给的、殿里拿的、路上捡的，一生一次
- **杀人越货** — 从谁身上抢的，那个人只死一次
- **必须炼制** — 原著里韩立自己开炉做的，有成败
- **能买到的** — 坊市摊子上真有货的，才可重复买

## 二、大衍诀：名字与来路都要说清

**先说名字。** 原著是《**大衍诀**》，不是「大衍剑诀」。它是一门**强化神识**的功法（养神、分神、御傀儡），跟剑没有关系。韩立真正的剑诀是《青元剑诀》。这两样常被混在一起说。

**来路分两段，横跨筑基到元婴：**

| 阶段 | 来源 | 内容 |
|---|---|---|
| **筑基期** | 同门**林师兄**来洞府夺舍，反被韩立灭了神魂，储物袋里一枚玉简 | **前四层** |
| **元婴期** | 远赴**极西之地**，在千竹教密室遇见寄身傀儡的**大衍神君**，以交易换得 | **后三层** + 傀儡术真传 |

林师兄的真实身份是**千竹教叛徒**（甚至可能是前少教主），随身带着门派秘术的前四层。

**绝不是墨大夫传授的。** 墨大夫只传了《长春功》，目的是夺舍，跟大衍诀毫无关系。

**也绝不是在坊市买来的。** 这轮把「绕去麓山殿用灵石换残卷」那句删掉了 —— 那是编的。

游戏里的落点：

```
百药园遇林师兄（际遇 e_lin，条件：已通关地火之屋）
        ↓ 他说「夜里别锁门」
翠屏山·洞府夜变（支线 linxiong，Boss：千竹教·林师兄）
        ↓ 反杀成功
得《大衍诀》前四层（唯一，全篇只此一处）
```

剧情里明说了只到前四层：「后三层在极西之地，那是元婴之后的事」—— 给以后留了位置。

## 四、唯一性怎么保证

标了 `unique: true` 的东西，四道门同时关：

1. **不掉落** — `Items.dropPool()` / `droppable()` 直接把 unique 排除，Boss 掉落 400 次抽样也抽不到
2. **不重复入袋** — `addToBag()` 里拦：身上已有一份，再捡、再买、再炼、再换都入不了袋
3. **不能卖** — 卖出拦一次（`此物有旧主 · 卖不得`），按钮也不显示
4. **不能拆** — 分解拦一次（`此物有旧主 · 拆不得`），按钮也不显示

首通才发地图奖励（`isFirstClear`），重刷只补一份灵石，所以「同一张图反复刷出孤本」这条路本来就不通。

## 五、炼制失败的代价

材料进了炉就不退，灵石退一半。界面每一行都写着成算：

```
青竹蜂云剑
成算 40% · 败则料尽
金雷竹 0/2  玄铁 0/3  玉髓 0/3  灵石 3200
```

失败提示：`炸炉 · 青竹蜂云剑废了（退回灵石 1600）`。
