### P1-1 视差实拍位移（确定性，非随机）

相机横移 `cam.x += 900` 时各层实际位移：

| 层 | 系数 | 实测位移 | 视觉 |
|---|---|---|---|
| 远山（双层剪影） | 0.18 | ≈ 162 | 缓慢漂移，几乎不动 |
| 寒林（枯树 + 岸线） | 0.45 | ≈ 405 | 中速 |
| 近景（石块 + 近株） | 0.80 | ≈ 720 | 接近地面速度 |
| 世界肌理（宣纸纹） | 1.00 | 900 | 与地面 1:1，锁世界坐标 |

三层错开 → 跑动时地面与远山产生连续位移差，D3「地面浮在原地」观感消除；帧内仅 `drawImage` 平铺 + 一次 `fillRect`，无每帧渐变，帧耗与基线持平。

### P1-5 双皮对等细节

- `openScroll()` 去掉 `save.skin !== 'guigu'` 的提前 `return` → 鎏金皮进图也走转场。
- `css/style.css` 新增 `jinSeal`：`0.6s` 径向渐变（`radial-gradient` + `inset box-shadow` 暗金细线 + 暗角），`body:not([data-skin="guigu"])` 下生效，中央留白区不被压黑。
- `__FR.wash()` 改为返回 `parallaxLayers().frame` → 两皮各自构建自己的框景层缓存（切皮时 `pxCache=null` 触发重建，隔离仍成立）。
- 推翻原「金皮下不生成晕墨层」过时断言，改为断言「jin 也生成同结构框景层 + 与墨皮是不同缓存」。
