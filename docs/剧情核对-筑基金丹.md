## 一、总评

**骨架是对的，但关节错了。** 大方向（七玄门 → 黄枫谷 → 血色禁地 → 筑基 → 燕家堡 → 金鼓原 → 乱星海 → 六连殿 → 天星城 → 结丹 → 虚天殿 → 奇渊岛）与原著一致，
28 张图里 **19 张站得住**，但有 **8 处硬伤会直接露馅**——不是细节问题，是把原著的因果关系接反了。

最要命的三条：

1. **叶师叔夺丹被放错了人生阶段**。原著是韩立手持升仙令刚入黄枫谷（炼气期、10 级左右）就被叶姓老者敲走入门配发的筑基丹，
   这才导致他被赶去百药园、只能冒险进血色禁地自己采药（144 章「筑基丹之争」→ 150 章「悔诺」→ 151 章「百药园」）。
   游戏把它挪到筑基闭关那一夜，让叶师叔来抢"剩下的筑基丹"——等于把整条因果链倒着插了一遍。
2. **结丹不是打怪掉出来的**。原著凝翠岛只是霓裳草引妖、杀妖取丹的猎场（393–396 章），
   攒够妖丹后回洞府「闭府苦修」，126 岁才在洞府里结丹（397–398 章「闭府苦修」「结丹与法宝」）。
3. **风希打不死**。风希是九级裂风兽，修为比肩元婴中期（195 岁），结丹中期的韩立在他面前只能暗算逃命。
   原著是「擒→赠碧焰酒助破结丹后期→逼炼风雷翅→绿液暗算三妖→斩毒蛟、夺翅逃」。

## 四、A 级硬伤（8 条，必须改）

### A1　黄枫谷·山门缺「升仙令 → 叶师叔夺丹 → 悔诺 → 百药园」
- **原著**：韩立持升仙令入门，本应配一枚筑基丹；叶师叔（灰衣老者）为给后辈铺路当场强夺，吴师叔仗义开口也护不住；许诺的补偿后来赖掉；掌门把他打发去百机堂，他自请去看百药园。
- **影响**：这一夺，是韩立"不再等施舍"的性格起点，也是他为什么必须进血色禁地的原因。缺了它，后面所有地图都变成"平白无故去打怪"。
- **改法**：`huangfeng` 剧情从 4 段扩到 8 段，加夺丹一段；`clearDesc` 改为"灵根差，丹也没了。百药园清苦，倒没人来抢。"

### A2　筑基闭关的 Boss 与剧情全错位
- **原著**：筑基发生在**地火之屋**，一炉丹、一个人、三日药力，全程无战斗；李化元随后收徒授《青元剑诀》，大衍诀是同期"夺得"（232 章）。
- **改法**：
  - 剧情重写为「地火之屋 → 丹成 → 服丹 → 三日 → 灵液化真元 → 筑基」；
  - Boss 从"叶师叔"换成**陆师兄**（太南小会结怨、闻韩立闭关筑基上门夺丹的那位）——他索要筑基丹是原著已有的线，比叶师叔合理；
  - 大衍诀来源改为"来犯者的储物袋"，不再挂在叶师叔身上；
  - 图名建议改「黄枫谷·地火之屋」。

### A3　燕家堡：动机、人物、结局三重错
- **原著**：李化元受**红拂**之托撮合韩立与**董萱儿**双修，派他带董萱儿赴燕家堡**夺宝大会**；燕家老祖已叛投鬼灵门，王蝉布阴火大阵+血灵大阵血祭七派弟子；韩立识破，破阵带董萱儿逃；被王蝉追，以**墨蛟之毒**暗算，王蝉中毒败退；逃跑时**报出"在下黄枫谷厉飞雨"**——这个假名王蝉记了两百年。
- **改法**：删"护送师妹赴婚事"；开场旁白改为赴会；中段改为血祭爆发；收尾改为破阵逃+报假名+下毒。这句假名台词是全篇最好的一处钩子，务必写上。

### A4　黑煞教：地点、首领、结局三重错
- **原著**：越国**京城·皇宫地宫**（不是胥国）；韩立护秦府时发现；李化元派**钟卫娘、宋蒙、武炫、刘靖**四人；四大血侍**冰妖、铁罗、青纹、叶蛇（吴九指）**；**教主即越皇**，筑基后期，吞血凝五行丹凝煞丹破结丹；**刘靖用真宝凤凰符斩青纹后被教主偷袭身亡**（不是自爆）；**武炫**落单被吸干精血；最终韩立以颠倒五行阵困越皇，**钟卫娘**以刘靖遗下的凤凰符宝斩杀。
- **战利品**：**虚天残图**（← 虚天殿的钥匙）、**血凝五行丹**、**玄阴经残本**。
- **改法**：这张图从"打一个叫胥王的魔头"升级成整条线的枢纽。Boss 名改**越皇**；精英改四大血侍；产出虚天残图。

### A5　古传送阵：修阵人错、同行人错
- **原著**：**齐云霄**修好古传送阵（351 章「齐云霄之死」，其后才有辛如音赠物）；韩立救下被魔道追杀的**南宫屏**，法力被吸去大半，拒绝她的邀请，**独自**传送；王蝉追至阵外，韩立靠**大挪移令**护身走脱。
- **改法**：辛如音→齐云霄（或"齐云霄修、辛如音守最后半年"）；删掉"拉南宫屏进阵"；收尾改成"她在阵外看着他走"——不一起走，反而更符合原著，也更有余味。

### A6　六连殿与凝翠岛拆错了，结丹方式错了
- **原著**：**一趟出海**里完成「捕婴鲤兽 → 乌丑强索 → 苗/古长老暴露身份灭口 → 布阵斩古长老 → 得降尘丹+混元钵」；凝翠岛只是霓裳草猎场；结丹在洞府闭关。
- **改法**：
  - `liulian` 改「六连殿·出海捕妖」：中段精英婴鲤兽 → 乌丑抢 → 终 Boss 古长老；
  - `ningcui` 改「凝翠岛·杀妖取丹」：不再产出结丹，改产出大量妖丹；
  - 新增一张「洞府·闭府结丹」剧情图（可复用 haian 位置），承接境界跨到结丹初期。

### A7　乱星海"修为跌落"是动漫设定，不是原著
- **原著**：韩立到乱星海仍是**筑基**（被南宫屏吸走的是法力，不是境界），落点在海底、飞天盾被水压挤碎，靠最后一张水遁符浮出海面。
- **改法**：`kuixing` 剧情改"境界还在，法力空得发慌"；顺手把"落海、盾碎、水遁符"写进去，比"从浪里救渔船"更贴原著。

### A8　风希不能被打死
- **原著**：风希**九级**裂风兽（≈元婴中期），结丹中期韩立打不过。风希擒他、赠**碧焰酒**助他破到**结丹后期**、逼他炼**风雷翅**；韩立用**稀释绿液的万年灵露**暗算三妖，**斩毒蛟、重伤龟妖**，卷翅逃；风希追杀万里。
- **改法**：Boss 从"风希"换成**八级妖兽·毒蛟**（风希请来的帮手，被斩）；风希作为剧情角色（不可战胜、追杀压迫感）；胜利条件改"翅成→暗算→逃"，`clearTitle` 改「风雷翅已夺」。
