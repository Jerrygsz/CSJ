# 鬼谷水墨皮 · 美术优化清单

> 依据：20261102n 版本实拍（战斗/大地图/对白/Boss战）。
> 分级：P0 = 一眼破坏风格；P1 = 明显欠一口气；P2 = 锦上添花。
> 成本：代码类 0 积分；素材类需图像生成或授权。

## 一、根本性问题：介质冲突

这套皮最大的短板不是"水墨不够多"，而是**三种介质混在一张画面里**：

| 介质 | 现状 | 观感 |
|---|---|---|
| 像素精灵（角色/敌人/道具） | 原版 12～16px 像素块，被滤镜糊成"泥点" | 与水墨背景脱节 |
| 矢量 UI（HUD/按钮/血条） | 现代圆角矩形、纯色填充 | 与纸卷气质冲突 |
| 水墨层（背景/插画/印章） | 新做的晕染、远山、朱砂印 | 风格正确但被前两者稀释 |

**结论：换皮要继续上台阶，必须先把"像素精灵"和"现代 UI 控件"这两块改造成水墨语汇，而不是继续往背景上加水墨。**

---

## P0 · 一眼破坏风格（建议优先）

### 1. 精灵改"墨阶重绘"
- 现象：主角/敌人仍是彩色像素小人，滤镜后变成脏褐色方块，边缘无笔意。
- 改法：**沿用现有像素网格，只换调色板和描边**——
  - 调色板压到 4 色：宣纸 `#f1ecdd` / 淡墨 `#8b867a` / 浓墨 `#2b2823` / 朱砂 `#b93325`；
  - 外轮廓统一 1px 浓墨，内部去杂色，只保留 2 阶灰；
  - 主角袍色保留一点赭石，敌人全部墨色，boss 加朱砂点睛（眼/角）。
- 成本：代码（sprites.js 加一层 pal 映射），半天。

### 2. 场地横向条纹（tile 接缝）
- 现象：地面出现等间距横向暗带——48px tile 里的竖向渐变每 48px 重复一次。
- 改法：tile 内改成**无缝纸纹/噪点**（不用竖向渐变）；竖向明暗只留在全屏 `washLayer` 里做一次。
- 成本：代码，1 小时。

### 3. 右侧技能钮是黑色圆盘
- 现象：右下三个深色圆钮（彩色图标）像从另一个游戏贴过来的。
- 改法：圆形改「墨圈 + 朱砂心」，或整体改**印章式方钮**（朱砂/墨底白文）；图标去彩色，改单色墨线。
- 成本：CSS + 少量图标重绘，2～3 小时。

### 4. HUD 血条/煞气条无笔意
- 现象：纯色块 + 圆角，仍是现代 UI。
- 改法：纸底 + 墨线框；填充改「墨色渐层 + 末端飞白（不规则收笔）」；数值用楷体小字，朱砂只给濒死。
- 成本：CSS + 一段 canvas 或 SVG 遮罩，2 小时。

## P1 · 明显欠一口气

### 5. 敌人/掉落物仍是原版小图标
- 灵石、草药、丹药、掉落物全是彩色小方块，是画面里最"像素"的部分。
- 改法：统一换成**墨点+朱砂** 3 阶小图（草=三笔、丹=圆点、灵石=菱墨块）。

### 6. Boss 插画只有一张共用
- 现象：所有 boss 都浮同一张狼形水墨图，且与屏上像素怪重复出现（画里一只狼、地上又一只怪）。
- 改法：① 按 boss 出 5～8 张专属异兽；② 插画改为**出场时全屏淡入 1.2s 后隐去**，作为"入场卷首"，不与战斗层长期并存。

### 7. 树/石/草是像素团
- 现象：绿色像素树丛在淡墨地面上很跳，是现有画面里唯一的高饱和元素。
- 改法：树改**3～5 笔墨点树**（浓墨干笔，无绿），石改淡墨晕块；草保留极少绿作点缀（符合"一点艳"）。

### 8. 缺"远中近"三层
- 现状：只有地面一层 + 底部远山。
- 改法：加一条**中景**——淡墨坡岸或枯枝剪影（透明度 8%～12%），配合已有远山与留白，形成三远。

### 9. 对白排版空、字重轻
- 现象：竖排对了，但 46vh 框里大片空白，正文偏细，缺句读节奏。
- 改法：控制列宽（每列 12～14 字自动换列）、字号 +1、首句下沉；右下角落一枚小印作"落款"。

### 10. 地图卡信息层级平
- 现象：地名、状态、描述、按钮同色同重，视线无落点。
- 改法：地名浓墨大字 → 描述淡墨小字 → 状态用**印**（已做）→ 按钮改墨线描边；卡片间距拉大，留白更奢侈。

### 11. 缺入场仪式
- 现象：进图硬切，风格突变时很突兀。
- 改法：加 **0.5s 卷轴展开过场**（上下纸帘向两侧拉开 + 墨色晕开），纯 CSS transform。

### 12. 缺"惊艳一刻"
- 现象：暴击/濒死/破境都只是数字变大。
- 改法：暴击落一枚朱砂小印；濒死屏幕四角漫朱砂；破境全屏落墨 + 楷体大字压屏（0.4s）。

## P2 · 锦上添花

### 13. 字体依赖系统楷体
- 安卓部分机型无 KaiTi，会 fallback 到默认黑体，"国风"瞬间掉一半。
- 改法：内嵌**思源宋/楷体子集 woff2**（约 80～150KB，只含常用 1500 字）。

### 14. 装裱绫边
- 面板外圈加一圈浅米色绫边 + 细墨线，模拟立轴装裱（易过度，慎用，只给关键弹窗）。

### 15. 图标系统不统一
- 界面里仍有 emoji 类图标（⚔️🔥等），与楷体界面出戏。
- 改法：统一成墨线 SVG 图标集（12 枚足够）。

### 16. 可读性底线
- 淡墨文字（--text-4）在纸底上对比度约 3.5:1，低于 4.5:1 无障碍线。
- 改法：正文类文字统一用 --text-2/--text-3，--text-4 只用于装饰性小字。

### 17. 缺听觉层
- 无水墨氛围音（古琴/箫/风铃），观感已到位但体感差一截。
- 需先定音源与授权。

## 二、建议的统一规范（避免越改越花）

**墨阶五级 + 两色纪律**，所有新增 UI 只许用这 7 个值：

| 名称 | 色值 | 用途 |
|---|---|---|
| 宣纸 | `#f1ecdd` | 底 |
| 淡墨 | `#8b867a` | 次要文字/装饰 |
| 中墨 | `#524d43` | 正文 |
| 浓墨 | `#2b2823` | 标题/描边 |
| 焦墨 | `#161512` | 极少，压重 |
| 朱砂 | `#b93325` | 点睛（每屏 ≤ 2 处） |
| 花青 | `#426476` | 法术/水汽 |

**三条铁律**
1. 一屏之内，彩色面积不超过 8%；
2. 朱砂只做"印"和"危急"，不做常规强调色；
3. 任何新元素先问：它是"墨"还是"纸"？两者都不是，就不该出现。

---

## 三、执行顺序建议

1. 第 1、2 条（精灵墨阶 + 去条纹）——一次性解决"脏"和"假"；
2. 第 3、4 条（按钮 + 血条）——解决 UI 断裂；
3. 第 6、7、8 条（boss/植被/中景）——补画面层次；
4. 第 11、12 条（过场 + 惊艳一刻）——补记忆点；
5. 第 13、15、16 条——工程与一致性收尾；
6. 第 17 条待音源。
