## 二、射程：100px → 内切屏幕的椭圆

### 为什么必须换掉旧值

旧做法是每门功法写死 `range: 360~640`。而屏幕逻辑尺寸 480×1040，玩家居中，**横向半宽只有 240**。也就是说旧射程**全部超过屏幕半宽**，玩家一直在打屏幕外的目标 —— 与「不超出屏幕」直接冲突。

### 为什么是椭圆不是圆

| 形状 | 满层半径 | 代价 |
|---|---|---|
| 圆（上限 240） | 各向 240 | 屏幕上下边缘（520）的怪「看得见打不着」，纵向浪费一半 |
| **椭圆** | 横 240 / 纵 520 | 满层正好内切四边，看得见的地方都打得到 |

椭圆形状恒定，纵半轴 = 横半轴 × (H/W)，**换设备比例也不会变形**。

### 公式

```
t = base + (1 - base) × (功法层数/上限) × 0.45
    base = (境界序号/7)^0.6            // 0 炼气 … 7 金仙
横半轴 ax = 100 + (W/2 - 100) × t^0.75
纵半轴 ay = ax × (H/W)
```

**为什么功法层数不能独占进度**：功法 `max` 只有 5~7 层，一局却跨 8 个大境界。让层数单独决定，炼气期把驱物术练满就顶到全屏，后面七个境界没有成长可给了。所以境界占大头，层数在其上再补最多 45%。

### 结果

| 境界 | 功法 0 级 | 功法练满 |
|---|---|---|
| 炼气 | **100×217** | 177×384 |
| 筑基 | 158×342 | 198×429 |
| 结丹 | 180×390 | 208×451 |
| 元婴 | 196×425 | 216×468 |
| 化神 | 209×453 | 223×483 |
| 合体 | 220×477 | 229×496 |
| 大乘 | 231×501 | 235×503 |
| 金仙 | **240×520** | 240×520 |

### 换功法的倒退

新功法从 0 级起步，射程会回落。实测最大倒退 **19px**（炼气满 → 筑基 0 级），随境界递减到 +5px。

19px 在 480 宽屏幕上约 4% 屏宽，读作「新功法生疏」，可接受。**没有做「历史最高射程记忆」** —— 那会让射程只涨不跌，玩家换功法的代价消失，等于取消了一个取舍。

### 弹道寿命同步

只改锁敌范围不够 —— 旧 `life` 写死 1.4 秒 × 360 速度 = 504px，比屏幕半高还远，子弹出画仍在判定。

现在 `life = 椭圆在该方向的半径 / 速度 + 0.04`，**能锁到的距离就是能打到的最远距离**。

追踪弹例外：初始方向随机，按长轴算再 ×1.5 抵掉转弯多走的路。

### 射程类被动（祭炼/顿悟的 m.range）

改成往**进度**上乘，而不是乘像素。进度到 1 时自然归零。

这是「不超出屏幕」的硬约束带来的：射程已经顶到内切椭圆，再乘多少都会被 clamp 回去。**后期射程被动的收益递减到 0**，这一点记录在案。

## 三、速度：每张图指定一只猎手

### 病灶

改之前全场最快的小怪 **90**，玩家 **96** —— 没有任何怪追得上你。「越往后越危险」只是纸面数字。

### 分档

| 档 | 判定 | 处理 |
|---|---|---|
| 猎手 | 本图选出的那一只 | 目标 98（玩家 ×1.02） |
| 快攻 | base ≥ 70 | 向 83 靠拢 |
| 普通 | base ≥ 45 | 向 71 靠拢 |
| 肉盾 | base < 45 | 仅 ×(1+0.22t)，**绝不含目标值** |
| 远程 | `TRASH_ARTS[type].t === 'cast'` | **完全不动** |

非猎手一律封顶 92：不越过玩家，留出「主动走位能拉开」的空间。

`t = (境界/7)^0.5` —— 开方，前期先把差距拉掉大半，别等到金仙才摸得到人。

### 猎手怎么选（踩过的坑）

**第一版用「本图最快的那一档」当猎手，结果把肉盾拉爆了**：虚天殿 / 昆吾山这类图最快只有 26，一选就把 26 速的尸傀拉到 80（+208%），肉盾定位直接垮掉，肉盾平均涨幅冲到 +88%。

改成：**猎手只能从「本来就会追人」的怪里选** —— base ≥ 55 或带 dash，取其中最快的一只。慢图里干脆没有猎手（虚天殿、阴罗宗、昆吾山、陇家四张），它们的「慢」是这张图的性格，不该硬拉一只变 3 倍速。

## 五、已知代价（下一轮的输入）

**阵亡从 5/21 升到 7/21。** 这是射程从 360~640 收缩到 100~240 的直接结果 —— 屏幕边缘的怪打不到了，玩家要么等它走近、要么主动靠上去，两种都在增加挨打机会。
