# 剧情对话与任务细节 · 原著核对

核对范围：《凡人修仙传》原著第一卷至第五卷（七玄门 → 黄枫谷 → 血色禁地 → 越国魔劫 → 乱星海 → 结丹）
核对对象：`js/maps.js`（练气篇对白）、`js/late.js`（筑基 / 结丹篇对白）、`js/story.js`（战斗内旁白）、`js/encounters.js`（际遇对白）
判定基准：**原著为准**；动画版只取其公认评价高的处理（《燕家堡之战》特别篇、墨大夫夺舍一节），且不超过原著信息量。

## 一、四处「时空错位」——最要紧的问题

### 1. 陆师兄被放错了整整一卷

**原状**：地火之屋的 Boss 是「同门陆师兄」，理由是「地火之屋就几间，你占一间我便少一间」，丹成当夜推门抢丹。

**原著**：陆师兄死在**血色禁地之前**。韩立从黄枫谷坊市买东西回来，在岔道上撞见他给陈巧倩下了催情迷药、正要连人带储物袋一起收走。韩立杀了他，**拿走他抢来的灵药**，给醒来的陈巧倩喂了一粒**忘忧丹**。

**问题**：地火之屋那一炉，原著里从头到尾只有韩立一个人。让一个已经死掉的人来抢丹，等于把两段剧情叠在了一起。

**已改**：
- 新增支线 `luxiong`「黄枫谷·下山岔道」，Boss 即陆师兄（新立绘 `neimen`，白袍玉冠，和杂役的深绿一眼分开）
- 际遇 `e_luxiong` 改成开这条支线的引子（药园里那句「那山道上小心点」，是伏笔）
- 地火之屋的对手换成**地火之灵**——地火之屋本来就靠地火，火脉一乱就是要命的事。用「环境」代替「人」，对原著的改动最小

### 2. 墨大夫不可能教青竹蜂云剑

**原状**：`story.js` 后山一节，「墨大夫：山中凶险，老夫传你青竹蜂云剑，自行护身」。

**原著**：青竹蜂云剑是韩立**结丹之后**用金雷竹炼的七十二口本命飞剑（青竹小轩那条线），比七玄门时期晚了近两百年。墨大夫给韩立的是《长春功》，给张铁的是《象甲功》；韩立的武技是跟**厉飞雨**学的**眨眼剑法**和**罗烟步**。

**已改**：那一段改成墨大夫给他《长春功》后三层并限期「练不到第四层莫来见我」，紧接着厉飞雨提着木枝在山道那头等他，教眨眼剑法与罗烟步。技能名也从「青竹蜂云剑」改为中性的「**控物术**」，到青竹小轩那条线才提「该炼青竹蜂云剑了」。

### 3. 叶师叔不是强抢，是交换——而丹是韩立主动让的

**原状**：山门一节写「叶师叔当众强夺」「吴师叔开口也没护住」「掌门把他打发去百机堂」。

**原著**：**叶师叔不能抢**。钟掌门有话：只许商量，不许强夺——升仙令代表七派对立功家族的承诺，赖一次，以后没人再替七派卖命。叶师叔提的是**交换**：一枚丹，换一批灵石法器，外加**任选一门差事**。韩立算过账（丹护不住，硬顶连命都没了），**主动让丹，自己挑了青石岭百药园**。叶师叔许诺的东西后来只给了一半，韩立没去要。

**已改**：整段重写。这一改把人物立住了——韩立不是被人欺负的苦主，是**会算账的人**；百药园也不是发配，是他自己挑的清净地（能安心修炼、能接触丹方）。「百机堂」是杜撰，已删。

### 4. 掌天瓶上没有「夺」字

**原状**：`story.js` 写「药庐窗下，一只青色小瓶被布层层裹着……瓶底刻着一个极小的『夺』字」。

**原著**：掌天瓶是韩立**在后山石缝里捡到**的，瓶身没有任何字。他夜里试出一滴绿液落在枯草上，草当场抽芽，才知道这东西能催熟灵药。

**已改**：改成捡瓶 + 试绿液 + 「这东西不能让第二个人知道」。这一改顺带把「掌天瓶绿液」这件道具的来源坐实了。

## 三、任务链上的两处断点

**1. 李化元收徒的时机错了**
原状写在「筑基之后，李化元召见收作记名弟子」。原著是**血色禁地出口**：七派长老赌哪一派采的药多，韩立交上去的药草压过所有人，李化元赢了这一场赌，当场收他做记名弟子。筑基之后授的是《青元剑诀》。

已改：`xsoutro` 补完整（点验 → 打赌 → 收徒），`zhuji_out` 只留授剑诀 + 去麓山殿换《大衍诀》残卷。

**2. 金鼓原是「弃子」，不是「断后」**
原著里黄枫谷的令狐老祖把一批低阶弟子留下来吸引魔道追兵，说白了是扔出去换时间。原文写「断后」还算体面，改成「低阶弟子往后撤，把追兵引开」，再让韩立自己点破——这也接上了他后面「我不再是黄枫谷的人」那句。

顺带把古传送阵挪回**灵石矿底下**（原著就是矿底那座），这样「往灵矿跑」和「齐云霄修阵」能接上。

## 五、墨大夫这一战补了什么

这是全书第一个大高潮，原状只有四句，缺了原著里最关键的几样东西：

- **尸虫丸**——墨大夫给他吃的毒，只剩一年寿命，逼他一年内修到第四层
- **魔银手**——那一战真正伤到韩立的东西
- **余子童**——附在墨居仁身上的修仙者，从头到尾撺掇夺舍的是他
- **六层对四层**——墨大夫算他第四层，他已经第六层，这才是他活下来的原因
- **铁奴揭面是张铁**——原著最扎人的一笔
- **遗书那句「凭什么仙家能够遨游天地，而我等凡人只能做一只井底之蛙」**

这些都补进去了。张铁那条支线也跟着改了：原著里他**没有坟**（尸体被炼成铁奴，后来成了韩立的曲魂），所以「埋骨处」改成「铁匠棚」——砧台上压着那块铁牌，比一座坟更对。

## 六、没动的部分（判定为合理拓展）

| 内容 | 为什么保留 |
|---|---|
| 后山「石魈」旧矿洞支线 | 原著没有，但七玄门是武林门派、后山有矿，属于合理的江湖事 |
| 演武场与厉飞雨切磋 | 原著两人没打过，但切磋不伤和气，反而立住了七玄门的武林属性 |
| 百药园的「噬灵虫母」 | 种药的地方有虫害合理，只是把虫害做成了 Boss |
| 太南小会的「黑货散修」 | 原著小会本身就有见不得光的交易，这一条是「遇到人开支线」机制的载体 |
| 地火之灵 | 原著筑基无对手，游戏需要 Boss。用环境而非人，改动最小 |
