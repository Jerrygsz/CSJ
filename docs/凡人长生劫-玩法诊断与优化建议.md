# 凡人·长生劫 · 玩法诊断与优化建议（第 75 轮）

> 判断依据：读码（game.js / skills.js / maps.js / balance.js）+ 实机跑通「标题 → 进图 → 战斗 → 顿悟 → Boss」全流程截图。
> 不是凭印象评论，下面每条都带可复核的数据点。

---

## 一、核心玩法原子拆解

**核心动词：走位。**

玩家在战斗里唯一能按的东西是移动（拖动 / WASD）。攻击、技能、命中判定全部自动。所以这个游戏的内核不是「打」，是「在什么位置站着」。

**基础规则（4 条）：**

1. 站到能打到的位置 —— 功法自动锁定最近目标，离太远就是空放（`fireWeapons` 里 `nearestEnemy(a.range)`）
2. 别站在伤害里 —— Boss 弹幕、冲撞、召唤物
3. 站点能吃到东西的位置 —— 灵石 / 掉落 / 草药都有拾取半径
4. 攒够煞气就停一下，从三张卡里挑一张

**涌现复杂度：**
走位路线 × 功法组合（on-hit 环绕 / 领域减速 / 弹道穿透的站位需求完全不同）× 卡池叠加。
复杂度不在操作上（操作只有两个轴），在「带哪几门功法进去、站在哪」这两层。

**张力结构：**
- 短期生存：弹幕密度 vs 血量与减伤
- 短期追求：杀得越多煞气越快，顿悟越快
- 长期追求：境界等级（lv1→640）、功法层数、装备、转世余荫

**经典对标：**

结构上是**《吸血鬼幸存者》的骨架**（自动攻击 + 击杀喂养升级 + 局内三选一 + 局外永久成长），套了**关卡制剧情 RPG**的外壳。

但它只学到了 VS 的前半段，没学到后半段 —— VS 的核心不是「自动打」，是**「屏幕被自己的弹幕和敌人同时填满」的那种失控感**。这个游戏把敌人密度砍到 3~5 只，自动攻击就失去了表演对象。

## 二、核心乐趣诊断

**现在真正好玩的点是「修仙进境的仪式感」，不是战斗。**

证据：`REALM_LAYERS` 每一层都有具体的功法授予（炼气七层得金光罩、十层得定神符），`INSIGHT_SAY` 写了 24 句顿悟台词，Boss 有水墨插画层，结算文案是「人参够数了。只是那狼妖的骨头，比寻常野兽硬得多」。

这些是**叙事与成长的仪式**做得很好。但战斗本身 —— 玩家平均 15 秒杀 17 只怪、同屏永远只有 3 只 —— 提供不了「我很强」的体感。

一句话：**现在的爽感来自「我又进了一层」，不来自「我这一下打得很狠」。**

## 三、可玩性评估

| 维度 | 评分 | 依据 |
|---|---|---|
| 上手门槛 | **低**（操作）/ **高**（认知） | 操作只有移动，零门槛；但第一次进游戏要面对功法 / 层数 / 装备 / 灵石 / 祭炼 / 丹药 / 洞府 七套术语，标题页就有 10 个统计项 |
| 操作爽感 | **弱** | 全场唯一的主动操作是移动。没有闪避、没有主动技、没有按住/松开。打击反馈全靠自动弹道的 VFX 和飘字 |
| 决策深度 | **中偏低** | 三个决策点：带哪几门功法进图（战前）、三选一（局内）、打哪张图。其中局内三选一的选项质量是硬伤（见第四节） |
| 重复可玩性 | **低** | 83 张图线性推进，同一张图打第二遍时敌人配置、卡池、Boss 行为完全一样；三档难度只是数值倍率 |
| 目标循环 | 短 ✅ / 中 ✅ / 长 ⚠️ | 短：30~170 秒一局（`bossAt` 均值 119 秒 + Boss 战 35 秒）；中：83 图主线约 2 小时；长：境界到 640 级、转世 1/81 复利 —— 但这条线太长太抽象，中间没有里程碑 |

## 四、问题与风险（按杀伤力排序）

### 1. 密度不足 —— 爽感的天花板被焊死了

刷怪逻辑（`budget()`）：

```
interval = max(0.26, 1.0 - t * 0.0032)
batch    = (1 + floor(t / 70)) * 难度系数
```

开局 1 只/秒，110 秒时才 3 只/秒。玩家实测 15 秒杀 17 只（1.13 只/秒），**杀得比刷得快**，所以同屏稳定剩下 3 只。

上限写了 140（`G.enemies.length < 140`），实际永远到不了 10。

对比：吸血鬼幸存者开局就是十几个，中期一屏上百。**自动攻击这个机制的价值，完全建立在「有东西可打」上。** 现在 3 只怪、一排弹道打过去打死一只，屏幕又空了。

### 2. 卡池与「变强打怪」脱节 —— 三选一在很多时候是假选择

抽卡概率（`rollInsight`）：

- A 技能升级 **40%** —— mod 池是 `伤害 +25% / 范围 +30% / 攻速 +20% / 多打一发 / 持续 +50%`
- B 新神通 **25%**（受 `enlighten` 限制，池子很小，经常 fallback 到 C）
- C 本局被动 **20%** —— 移速 / 吸血 / 减伤 / 拾取 / 气血 / 煞气
- D 灵石 **10%**
- E 特殊 **5%**

实机截到的三组卡：

```
气血上限 +15   |  灵石 +30      |  驱物术 · 范围 +30%
拾取范围 +30%  |  移速 +10%     |  煞气 +15%
驱物术 · 持续 +50% | 移速 +10%  |  煞气 +15%
```

九张里只有两张跟「打得更狠」有关。而且 `持续 +50%`（弹道多飞 0.7 秒）、`范围 +30%`（锁敌距离变远）**在屏幕上几乎看不出来** —— 玩家选完了，没有任何反馈说「我变强了」。

VS 的卡池之所以爽，是因为「多一把武器 / 弹道数量 +1 / 范围肉眼变大」都是**看得见的变化**。这里最强的卡是 `count + 1`（多打一发），但它只占 A 类里 1/5，也就是总体的 8%。

### 3. 玩家没有「操作感」的抓手 —— Boss 战变成绕圈

Boss 有冲刺（`dashing`）、环形弹幕、召唤，机制是够的。但玩家能做的只有走。

死境难度下（怪 hp×3.1、dmg×2.2）玩家的唯一应对是「离远一点」，这不是操作，是退让。

**当下的爽游几乎都给了 1 个主动按钮**：哈迪斯的冲刺、土豆兄弟的闪避、甚至小游戏里的「翻滚」。这一个按钮把「我只能跑」变成「我能处理」。

### 4. Boss 没有压迫感 —— 体型和玩家同级

Boss 的 `scale` 是 3.1~4.4，但精灵图本身小，实机截图里贾天龙和玩家差不多大。血条在最顶端（红条），和玩家的生命条上下呼应，视线被分散。

对比：VS 的死神、哈迪斯的冥王 —— 占据屏幕 1/3 才是「Boss」。

而且 59/81 张图是 `bossAt: 0`（进图直接单挑），**没有预热就开始打**，玩家刚看完剧情对话，下一秒就是一个跟自己一样大的东西站在屏幕中央。

### 5. 失败零成本 —— 前面做的「危机感」被架空了

`gameOver()` 只做了三件事：存最好成绩、播放音效、弹结算。等级、装备、功法层数全保留，重打同一张图即可。

所以第 74 轮把 Boss 单击做到 7.5%~10.5% 气血（裸装 10~13 击）本身是对的，但**玩家感受不到威胁**：死了就重来，代价是 40 秒。

危机感 = 伤害 × 失败的代价。现在第一项做完了，第二项是 0。

## 五、优化建议（分优先级）

### 高优先级（立刻改，全部是调参不改架构）

**① 把密度拉到 3 倍**

```js
// game.js budget()
const batch = Math.max(1, Math.round((2 + Math.floor(t / 30)) * cnt));   // 原来 (1 + floor(t/70))
const interval = Math.max(0.20, 0.7 - t * 0.0035);
```

目标：开局同屏 8~12 只，中段 25~35 只。分两档试（×2 / ×3）实测手感再定。
同步要把小怪血量降下来一点（`BALANCE.trashHpK` 已有接口），否则会变成「打不完」。
上限 140 不用动，先看能不能摸到 40。

**② 重做卡池配比：让 80% 的卡「看得见」**

```js
// rollInsight 概率
A 技能升级 45% / B 新神通 20% / C 被动 20% / D 灵石 8% / E 特殊 7%

// SKILL_MODS 只保留强感知的，不可见的降权
{ k:'count', v:1,    weight: 3 }   // 多打一发 ← 主力
{ k:'dmg',   v:0.30, weight: 2 }   // 伤害 +30%
{ k:'cd',    v:0.25, weight: 1 }   // 攻速 +25%
{ k:'rad',   v:0.35, weight: 2 }   // 面积/半径 +35%（burst/field 才给）
{ k:'dur',   v:0.50, weight: 0.5 } // 持续 +50%（Least preferred）
{ k:'range', v:0.30, weight: 0.5 } // 锁敌距离 ↑（不可见，降权）
```

被动卡池里 `拾取范围` 直接移除（它已经能通过装备解决，占掉一次顿悟太浪费）。

**③ 加一个主动按钮：闪身**

这是本轮唯一建议「加东西」的地方，因为它是把「只能跑」变成「能处理」的最小改动。

```
名称：罗烟步（已经有一门同名被动功法，正好复用世界观）
效果：朝移动方向瞬移 90px，途中 0.3 秒无敌
冷却：2.5 秒（HUD 走现成的 quickbar 三格之一）
限制：不能穿 Boss 本体
```

代码落点：`G.player.iv`（无敌帧）已有，`F.teleport` 已有，`quickbar` 已有。**几乎零新增系统。**

**④ 失败给「快速重开」，不给惩罚也不给白给**

现在的失败 = 重打 40 秒。改成：

- 死亡瞬间弹「再来一次」按钮，直接重进同一张图（跳过剧情，0 秒加载）
- 保留本局顿悟的 **一半**（四舍五入），让玩家觉得「这次没白打」

这一条同时解决「失败无感」和「重复可玩性」：失败变成一次有进度的重试，而不是一次清零。

### 中优先级（体验增强）

**⑤ Boss 入场演出 + 体型放大**

```
进 Boss 前：镜头推近 0.6 秒 → 定格 → Boss 名字压屏 → 血条从中间展开
Boss 视觉尺寸：scale × 1.5（或至少保证占屏高 1/5）
血条：分段（3 段），每破一段换一个 Boss 行为
```

成本低（都是现成的 DOM/Canvas 动画层），收益是「这一下认真了」的心理开关。

**⑥ 每局给一个随机主题，解决「83 张图打第二遍一模一样」**

进图时从 3 个里随机一个：

- 「煞气充盈」：顿悟门槛 −30%，本局卡更多
- 「妖气浓重」：刷怪 ×2，掉落 ×1.5
- 「压制」：玩家伤害 −15%，但 Boss 血量 −25%

不改数值平衡，只改每局体感。这是 roguelite 的「局内变异」，成本极低。

**⑦ 每 5 关给一个「机制变招」，而不是新数值**

现在的 83 张图，机制变招集中在 Boss 上；小怪从第一关到最后一关是同一套 AI（走、撞、偶尔冲锋）。

建议每 5 张图加入一种小怪新行为：分裂 / 自爆 / 远程 / 护盾 / 召唤。**这是「每关不一样」最便宜的来源。**

### 低优先级

⑧ 画面提亮：战斗底图几乎纯深色，只有几棵草。加一层地面纹理/边界感，能让「我在哪」更清楚。
⑨ 结算分享卡：一局打完生成一张「本局最佳一击 / 最高连斩 / 用时」的竖图。现在的传播素材全靠剧情，缺一局结束的可分享物。

### 可删清单（做减法）

1. **快捷栏三格** —— 实机是三个空圆点，占屏幕右下角，玩家第一次看会以为是按钮。没装满就别显示。
2. **顶部 HUD 的「时间 / 斩 / 袋」** —— 战斗中最不重要的三个数字，占了最贵的位置。
3. **灵石进卡池** —— 「灵石 +30」需要玩家理解祭炼系统，而祭炼在局外。局内给一个看不懂的货币，是纯噪音。
4. **「袋 0」** —— 战斗里玩家不会背包，这个数字全程不变。

## 七、参考案例

**《吸血鬼幸存者》（成功的密度）**
它的第一分钟很无聊（一把鞭子、几只蝙蝠），但第 5 分钟开始屏幕被敌人填满，第 15 分钟玩家的弹幕本身构成了一个「自动运行的杀戮机器」。爽感的来源不是数值变大，是**画面上可数的东西变多**。
→ 迁移点：把 `budget()` 的 batch 抬上去。这是本作最缺的一环，也是改动成本最低的一环。

**《土豆兄弟》（成功的短局结构）**
每局固定 20 波、每波 20~60 秒、波间进商店。它把「短局 + 明确节奏 + 每局不同」做到极致。
→ 迁移点：本作 83 张图是「一次性内容」，土豆兄弟是「可重复内容」。不需要改关卡设计，只要给每局加随机主题（第 ⑥ 条），同一张图打三遍就有三种体感。

**反例：多数「自动战斗 + 关卡制」的失败手游**
借了 VS 的自动攻击，但敌人密度、成长曲线、局内变化一个都没跟上，最后变成「看小人自动打过关」。玩家第一次觉得省事，第三次就卸载。
→ 本作现在的同屏 3 只，正走在这条路上。好在骨架是对的，来得及改。

## 八、一句话总结

**这个游戏的框架已经对了（竖屏、单手、短局、自动攻击、三选一、修仙叙事），现在的问题不是「玩法不对」，是「爽感曲线是平的」——**
敌人太少（3 只）、卡太虚（60% 与战斗无关）、手太闲（只有移动）、死太轻（重来 40 秒）。

四条全是调参级改动，不需要重构。

## 9.2 过程中被数据推翻的两条判断

**第一条：上一轮说的「同屏只有 3 只」是测量假象。**
那次测量让玩家贴脸打，怪一出生就被秒。改成"正常走位"后实测：**同屏 46~126 只**。
真实病灶不是「怪太少」，是「刷怪 1~3 只/秒、玩家只能杀 0.4~1.3 只/秒」，缺口只增不减 —— 玩家是被**淹死**的，不是被打得太闲。

**第二条：病灶不在节奏，在小怪血量的双曲线复利。**
修完刷怪后，lv36 以上仍然 10 秒内全灭、0 击杀。查到根因：

```
小怪血量 = def.hp × hpMulBase
           ↑            ↑
     自带跨图曲线     按等级再标一条
   狼 12 → 幽奴 28 万   k^0.94 × 系数
```

两条成长曲线相乘 = 复利。实测 lv36 的鬼灵门弟子 765 血，玩家秒伤 70，**一只怪要打 11 秒**（设计意图 0.6 秒），偏了 18 倍；lv460 偏了 1000 倍以上。

修法（`makeEnemy` + `refHpOfMap`）：只取 `def.hp` 的**同图相对硬度**（开方压缩），绝对血量统一由 `ENEMY_BASE_HP × hpMulBase` 决定。同图里该厚的还厚，但不再跨图复利。

- **中后期从 10/10 全灭变成 0/10 阵亡**。这是这轮最大的一块：主线中段本来就打不过，跟「爽不爽」无关，是「能不能玩」。
- 阵亡还剩 5/21，都是前中期几张图（含首关），说明危机感还在，没有变成无脑推平。

性能没变差：平均帧耗 0.071ms → 0.064ms（怪少了反而更快）。
