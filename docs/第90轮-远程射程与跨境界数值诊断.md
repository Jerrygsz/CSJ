## 三、方案

### 3.1 射程：椭圆覆盖整个可视区（100px → 满屏）

**为什么不用圆形 240**：竖屏纵向有 432 的可视区，圆形 240 会让屏幕上下边缘的怪"看得见打不着"，浪费一半屏幕，也不叫"全屏"。

**定义**：射程是一个椭圆，横半轴 `rx`、纵半轴 `ry = rx × (H/W)`。当 `rx = 240` 时，椭圆正好内切于屏幕四边。

| 层数 | rx | ry | 覆盖 |
|---|---|---|---|
| 1 层 | **100** | 180 | 约屏幕 42% |
| 满层 | **240** | **432** | 正好贴满四边，不溢出 |

成长公式（每门功法独立，按自身层数上限到 240）：

```
rPerLv = (240 - 100) / max
rx = 100 + rPerLv × 层数
```

| 层数上限 | 每层加 | 1层 | 满层 |
|---|---|---|---|
| 5（火弹术） | 28.0 | 100 | 240 |
| 6（驱物术等） | 23.3 | 100 | 240 |
| 7（大庚剑阵等） | 20.0 | 100 | 240 |

**这是一次收缩**：横向从 360~640 收到 100~240。代价是后期横向射程降约 55%；换来的是"打得着的永远看得见"，以及射程本身成为一条能被感知的成长线。

### 3.2 功法基础伤害：按境界重排

**目标带（写死，作为验收标准）**

| 对象 | 目标 TTK | 现状 | 依据 |
|---|---|---|---|
| 小怪（全功法齐发） | **0.18 ~ 0.30 秒** | 0.006 ~ 0.225 | 割草要有手感，不是"看不见" |
| 小怪（单门功法单独开火） | **2.5 ~ 4.0 秒** | 后期 7~12 秒 | 换功法要能感觉到"变强了" |
| 精英 | 3 ~ 5 秒 | 既定 | `balance.js` |
| Boss | 30 ~ 44 秒 | 既定 | `balance.js` |

**反推公式**

```
单门满层单发 = (该境界小怪血 ÷ 单门TTK) ÷ (count/cd) ÷ 境界伤害倍率 ÷ 攻速倍率
```

现在的问题不是"整体伤害不够"，而是**单门太弱、门数太多**：境界奖励的功法会全部挂在身上同时开火，十几门叠出的总 DPS 掩盖了每一门都很弱的事实。

### 3.3 无远程怪：速度锚定玩家移速，不再写绝对值

**根因**：`def.spd` 是绝对值（26~90），玩家是 96 且随境界涨 —— 差距只会越来越大。

**改法**：无远程能力的小怪，速度改为「玩家基础移速 × 系数」，按角色分档，而不是一刀切加速：

| 类型 | 系数 | 现在的怪 | 效果 |
|---|---|---|---|
| 肉盾 | **0.58** | 尸傀 26 / 石人 30 / 巨猿 | 追不上，但很硬，卡位压迫 |
| 普通 | **0.74** | 恶狼 62 / 马贼 48 / 魔修 | 能追上，玩家可拉扯 |
| 快攻 | **0.86** | 毒蛇 74 / 蝙蝠 68 | 追得紧，必须边打边退 |
| 猎手 | **1.02** | 死士 86 / 尸魈 / 林女（带 dash） | **比玩家快**，靠冲刺贴身 |

这样"越往后越快"自动成立（玩家越强、移速越高，怪跟着抬），而相对威胁恒定 —— 不会出现"前期被追死"或"后期追不上"。

带远程能力（`t:'cast'`）的 15 种**不动**：它们的威胁来自弹幕，本来就该慢。

## 四、需要你拍板的两件事

### ① 射程收缩，接不接受

横向射程从 360~640 收到 100~240，后期相当于砍掉一半多。好处是"打得着的都看得见"，坏处是远程手感明显变近。

### ② 猎手型怪要比玩家快

要让"无远程怪真的能造成伤害"，必须有一档怪速度超过玩家移速（1.02 倍）。这会让玩家**逃不掉**，只能靠击杀或绕障。这是"死亡危险"的来源，但也会明显提高难度。

## 五、验证契约（跑之前写死）

| 字段 | 内容 |
|---|---|
| `decision` | 射程改为椭圆成长；无远程怪速度锚定玩家移速；功法 base 按境界重排 |
| `evidence_level` | 现状 L2（解析模型 + 实跑采样，未做 A/B）→ 改后目标 L3（pacing 全库实测对照） |
| `primary_bottleneck` | **无远程怪速度上限 90 < 玩家移速 96，且不随境界增长** —— 这是"无敌"的机制性根源，不是数值大小问题 |
| `released_variables` | **2 个**：① 射程公式 ② 无远程怪速度系数。功法 base 与怪血本轮**不动**，避免与难度改动混在一起归因 |
| `held_constant` | 小怪血量、小怪伤害、Boss 血量、玩家移速、功法 base、境界倍率、掉落 |
| `success_criteria` | ① pacing 阵亡率落在 **4~8 / 21**（基线 5）；② 无远程怪贴身命中率 ≥ 25%（现接近 0）；③ smoke 294/0；④ 帧耗 < 1.2ms |
| `rollback_trigger` | 阵亡率 > 10/21（难度失控）或 < 2/21（等于没改）→ 回滚速度系数；射程若导致 pacing 击杀数下降 > 20% → 回滚射程 |

**为什么功法 base 与怪血不在本轮动**：它们和难度改动耦合，一起放会无法归因。先证明"速度是主瓶颈"，再单独一轮处理伤害与血量的对齐。
