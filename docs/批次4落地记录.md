## 三、实拍发现并修掉的问题：深底吞墨

**批次3 只测了浅纸底的后山，没撞上这个**。首批 18 张里：

- 9 张主线图有 `m.inkBg`（浅纸底 `#ddd6c3` / `#e9e3d4`）；
- 9 张游戏增补图**没有 `inkBg`**，`buildGrass` 退回 `m.bg.base`（`#2d2c2a` 一类深墨底）。

第一次实拍 `shiku` 时肉眼看到整屏深底、装饰和贴地块几乎被吞没——结构校验全绿但画面不对，正是批次3 那条「结构通过 ≠ 能用」教训的重演。

**修法**：新增 `sc3DarkBase(m)`，与 `buildGrass` 完全同款取底（`m.inkBg || m.bg`），亮度 < 110 判为深底；`sc3Colors(jin, tone, dark)` 在深底时把整组墨色按 `255 - (255-v)*0.35` 抬到浅灰区（保持各通道相对明暗），相当于「淡白墨」。色相不变、仍是低饱和灰阶，**地图数据一个字段都没改**。

复拍 `shiku / xuechi / heisha`：装饰清晰可见、不过曝、不刺眼，四角摆块与中央留白仍在。浅纸底 9 张保持原淡墨，零回归。

## 九、构图化改造（版本 20261105F → 20261105G）

Jerry 反馈「目前做好的还是有些杂乱，要先改得既符合原著小说描写，又显的高级」。诊断结论：**杂乱的根因不是画得不好，是 18 张图共用同一套「均匀撒点」构图**——阶段二只把考据翻译成「装饰种类 + 墨色浓淡」，没翻译成「画面怎么摆」。

### 诊断（代码证据）

| # | 问题 | 证据 |
|---|---|---|
| 1 | 满屏均匀噪点 | `genChunk()` 每 240×240 chunk 固定 6 个、坐标均匀随机、类型独立按权重抽 → 视野约 90 个装饰铺满；`tainan` 高山雾和 `xuese` 石墙一样满 |
| 2 | 原著主景被埋 | 台账写了「彩霞山山门 / 中心区四道铜门 / 太南山高山雾」，但地标 alpha 0.45、与装饰同尺寸、坐标散列 |
| 3 | 方符号感、笔法两套语言 | `ruin/lantern/banner/gate/stele/stair` 用实心 `rect()` 直角块，读成散落方形图标；`bamboo/pine` 却是曲线点叶 |
| 4 | 没有远中近 | `drawDecor()` 只有纵向 `dr` 大气透视 |

### 改法：让台账里的 `art` 当画面主角

`art` 字段阶段一就写好了每张图的原著理想画面（「石墙大圆圈＋四道铜门」「无窗石屋剖面＋中央法阵」「山顶小寺剪影」「两排棚檐夹出一条窄留白」），全是**一张图只立一个主景、其余留白**的水墨章法，阶段二没用它。本轮把它结构化成 `composition` 并落地。

| 项 | 阶段二 | 构图化 |
|---|---|---|
| 主景 | 1~3 个随机散列淡地标 | **全图只 1 个**原著景物，8 类专属形状 `narrowgate / pool / stonehut / temple / stonering / grove / minehead / shed`，专用浓墨色板 CF + 连续实笔 + 全 alpha，按 7 种章法定构图位、避中央玩法区 |
| 装饰 | 6 种按权重逐格独立随机，约 90 个 | 低频连续相位判「连通聚落 / 留白」，组内同种 + 大小浓淡错落，`palette` 收窄到 1~3 种；`breath` 1~3 控密度 |
| 笔法 | 实心 `rect()` 直角块 + 曲线点叶混用 | 实心矩形全清，断续笔线 / 没骨墨团 / 石棱皴擦；**配景虚笔、主景实笔** |
| 贴地 | 四角摆块固定套路 | 按 `layout` 摆软边墨块（环抱 / 横带 / 夹景 / 斜势 / 只留一角） |
| 次景 | 与装饰争视线 | alpha 0.20 + 缩小，退到纸后 |

### 实拍自查（两轮修，13 张亲眼看）

| 轮 | 发现 | 修法 |
|---|---|---|
| 1 | 主景沿用配景 0.72 折扣太淡：`qixuan` 山门读成散线、`tainan` 小寺读成牌坊、`mishi` 石屋读成圆蘑菇；聚落里全是同灰圆石团 | `sc3Bake(..., strong)`：主景 `P` 不打折、`brush` 连续实笔、软边罩减弱；重画 3 个主景；`moss` 改石棱皴笔；聚落加 `a` 浓淡系数与 `s` 错落 |
| 2 | `mishi` 读成「相框里的镜子」；深底 `shiku` 主景与装饰同亮度不分主次 | 主景专用 `CF`（浅底更黑 / 深底更亮）；石屋改欹斜墙线 + 石缝、去掉居中椭圆；矿洞口改笔线围合留白 |

**结构校验当时全绿，问题全靠实拍看出来**——又一次「结构通过 ≠ 能用」，且必须同时覆盖浅底与深底样本。
