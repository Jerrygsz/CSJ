## 一、境界体系（原著 V2C127 分档）

原著把修仙界分三档：

| 档次 | 境界 | 说明 |
|---|---|---|
| **下境界** | 炼气 → 筑基 → 结丹 → 元婴 → 化神 | 人界可修 |
| **中境界** | 炼虚 → 合体 → 大乘 | 灵界为主 |
| **上境界** | 渡劫 | 过关即飞升仙界 |

### 寿元与天劫（原著 V7C1219）

| 项 | 内容 | 依据 |
|---|---|---|
| 小天劫 | 元婴、化神 每 **300 年**一次 | V7C1219 |
| 大天劫 | 炼虚、合体、大乘 每 **3000 年**一次 | V7C1219 |
| 仙劫 | 飞升真仙界所历 | V7C1219 |
| 结丹寿元 | 五六百年 | V4C398 |
| 元婴寿元 | 千余年 | V5C639 |
| 化神寿元 | 比元婴多千余年（约两千年） | V6C928 |
| **炼虚寿元** | **无限制 / 数以万计**（须在灵界，人界天地元气不足仍有限） | V7C1219、V9C1585 |
| 大乘寿元 | 远超常人想象 | V9C1673 |

### 分阶
- 炼虚：初期 / 中期 / 后期（原著三阶均常见）
- 合体：初期 / 中期 / 后期
- 大乘：原著多用「大乘期」，**不分初/中/后**（`大乘中期` 全文 0 次）
- 渡劫：作**关口**，非长期阶段（`渡劫期` 仅 5 次；V9C1518 有「渡劫期」用法）

### 突破条件（关键）

| 关口 | 条件 | 依据 |
|---|---|---|
| 化神 → 炼虚 | **五行合一**（须兼修多属性功法，单一属性难进阶）+ **腾龙丹**（炼虚级灵药，三万年一结果） | V7C1219、V9C1364 |
| 炼虚 → 合体 | **合体丹** + 真灵之血/真灵鳞片一类灵物 + 渡三千年大天劫 | V10C1770、V9C1359、V8C1341 |
| 合体 → 大乘 | 渡大天劫 + 玄天之宝/仙丹一类 `[原著·待核]` | V7C1219 |
| 大乘 → 真仙 | **仙劫**；「真仙之身」「九劫」 | V12C2419–2422 |

> ⚠️ **禁止自造**：`炼虚丹`、`大乘丹`、`渡劫丹` 原著 **0 次**，不得使用。
> 炼虚的核心是**五行合一**，不是吃丹。
