# 校验规则（validator）

> 兜底自查。每次改游戏文本/数值/剧情后，逐条过一遍；提交前必须全绿。

## A. 名词（`whitelist.json`）

- [ ] 所有专有名词能在 `whitelist.json` 找到，或原著可查
- [ ] 无 `forbidden` 词（练气期 / 下品灵石 / 中品灵石 / 上品灵石 / 大衍决 / 翠屏山）
- [ ] 别名使用正确（早期用「小瓶」，不用「掌天瓶」）

## B. 修为（`progression.md`）

- [ ] 境界名/层数正确（炼气一至十三层）
- [ ] 突破条件齐备（筑基需筑基丹等）
- [ ] 无跳境界
- [ ] 寿元不超表（结丹五六百年、元婴千余年）

## C. 经济（`economy.md`）

- [ ] 灵石等级用 低阶/中阶/高阶/极品
- [ ] 价格量级对照 V2C131
- [ ] 无现代货币

## D. 战斗（`combat.md`）

- [ ] 无网游数值词（血条/暴击/秒杀/战力）
- [ ] 技能名原著可查
- [ ] 战斗描述用法力/法宝/符箓/禁制语汇

## E. 掉落（`loot_tier.md`）

- [ ] 小怪不掉高层宝物
- [ ] 关键丹药来源固定（筑基丹不走野怪）
- [ ] 顶级法宝只走剧情/秘境

## F. 剧情（`plot.md`）

- [ ] 不提前解锁后续卷
- [ ] 主线走向不变
- [ ] 地图顺序与卷序一致

## G. 地理（`geography.md`）

- [ ] 地名原著可查（翠屏山禁用）
- [ ] 势力归属正确（黄枫谷在越国）

## H. 人物（`npc.md`）

- [ ] 无 OOC（韩立谨慎、算计、低调）
- [ ] 无现代腔/网络梗
- [ ] 称呼合礼数

## I. 术语（`glossary.md`）

- [ ] 无禁用语
- [ ] 半文半白

## J. 化神后（灵界篇）

- [ ] 境界按「中境界（炼虚/合体/大乘）→ 上境界（渡劫）→ 真仙」推进
- [ ] 炼虚靠**五行合一**，不是吃丹
- [ ] 无 `炼虚丹` / `大乘丹` / `渡劫丹`（原著 0 次）
- [ ] 地图在 `灵界篇-蓝图.md` 表内，或标 `[原创]` 待批
- [ ] 玄天之宝/真灵之血只走剧情/秘境

## 可执行检查

```bash
# 1) 禁用词扫描（游戏代码 + 文案）
grep -rnE "练气期|练气[一二三四五六七八九十]+层|下品灵石|中品灵石|上品灵石|大衍决|翠屏山" js/ | head -50

# 2) 网游词扫描
grep -rnE "血量|血条|暴击|闪避|秒杀|副本|刷怪|经验值|战力值|技能CD|冷却|氪金|金币" js/ | head -50

# 3) 名词白名单核验（新词）
grep -oE "[一-龥]{2,6}(宗|门|派|谷|山|城|岛|海|殿|坊|丹|诀|剑|鼎|珠|符|阵|兽|妖)" js/items.js | sort -u
```

> 建议后续把上述检查写成 `tools/validate_canon.py`，一键跑。

## 置信与兜底

- 拿不准 → 标 `[原著·待核]`，不得当定论写进游戏。
- 原著查不到 → 标 `[原创]`，**必须用户批准**才可进游戏。
- 冲突时：**原著 > 游戏现状**；改动须同时更新本目录对应表。

## 提交前清单（缩略）

1. 跑禁用词扫描，0 命中。
2. 新增名词入 `whitelist.json`。
3. 新增地图/道具/剧情在对应表登记。
4. 更新 `README.md` 的「高优先级偏差」表（若修复）。
