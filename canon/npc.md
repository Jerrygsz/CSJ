## 二、韩立语言规范（最重要）

- **话少、务实**：能一句说完不说两句；不喊口号、不发宏愿。
- **内心独白多权衡**：遇事先算利弊、想退路、防陷阱。
- **称呼**：对前辈称「前辈」，对同辈称「道友」，自称「我」或「在下」。
- **语气**：半文半白、古白话；不用现代词、不用网络梗。
- **禁止 OOC**：
  - 不热血冲动、不路见不平就上（会先算代价）
  - 不轻信陌生人、不炫富、不张扬
  - 不圣母、不说教、不现代价值观输出

## 三、通用对话规范

| 项 | 规范 |
|---|---|
| 称呼 | 前辈 / 晚辈 / 道友 / 师兄 / 师弟 / 师姐 / 师妹 |
| 自称 | 我 / 在下 / 老夫（老者）/ 晚辈（对前辈） |
| 语气 | 半文半白，古白话 |
| 禁用 | 现代口语连篇、网络用语、英文词、emoji |

**禁用词示例**：OK、没问题、搞定、安排、加油、大佬、666、绝了、真的会谢、内卷、躺平、情绪价值、PUA、割韭菜、破防、社死。

## 四、角色台词风格卡（写作时对照）

- **韩立**：短句、少感叹、多思量。示例语气：「此事……容我想想。」「前辈所言，晚辈记下了。」
- **墨大夫**：表面温和、话里带钩。示例：「立儿，为师也是为你好。」
- **张铁**：直白、憨。示例：「少爷说怎么办，我就怎么办。」
- **厉飞雨**：爽利、带江湖气。示例：「韩师弟，这事我替你担着！」
- **李化元**：长者口吻、点到为止。
- **南宫婉**：清冷、简短。

## 五、铁律

1. 任何 NPC 台词不得出现现代腔/网络梗。
2. 韩立不得 OOC（谨慎、算计、低调是底线）。
3. 称呼须合原著礼数。
4. 人物身份/关系拿不准时标 `[原著·待核]`，不得臆造。
