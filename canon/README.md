# 《凡人·长生劫》原著约束体系（Canon）

> 本目录是游戏内容的**权威依据**。规则：游戏必须遵守原著，不自造词、不跳境界、不提前解锁、不乱改走向。
> 任何改动**先查本目录，再动代码**。

## 工具

| 脚本 | 用途 |
|---|---|
| `tools/novel_index.py` | 重建章节索引与目录 |
| `tools/novel_get.py` | 按章/卷/行号/关键词抽取原文 |
| `tools/build_whitelist.py` | 候选词→原文核验 |
| `tools/finalize_whitelist.py` | 补正名/别名/禁用映射 |
| `tools/build_lingjie_terms.py` | 化神后（灵界/魔界/真仙）术语并入白名单 |
| `tools/validate_canon.py` | 禁用词扫描，区分玩家可见/注释 |

常用：
```bash
python tools/novel_get.py --chno 214              # 读第214章
python tools/novel_get.py --search "筑基丹"        # 查关键词命中行
python tools/novel_get.py --vol 3 --maxchars 3000 # 读第3卷前3000字
```

## 置信标注（全目录统一）

- `[原著]` 有原文依据，附卷/章
- `[原著·待核]` 方向对、细节待核，**不得当定论**
- `[游戏]` 游戏现有设定，未必合原著
- `[原创]` 游戏自造，**须替换或用户批准**

## 强制流程

1. 改任何游戏文本/数值/剧情前，先查对应表。
2. 新词必须先确认在 `whitelist.json` 或原著出现；否则不得使用。
3. 新增地图/道具/剧情，必须能在 `plot.md` / `geography.md` / `loot_tier.md` 找到原著依据；找不到就标 `[原创]` 并请用户批准。
4. 提交前跑 `validator.md` 清单。
