# 修为与突破（progression）

> 管：境界名称、层数、寿元、突破条件。防：跳境界、无丹药乱突破、用等级/经验解释修为。

## 一、境界总序（原著 V2C127 分三档）

| 档次 | 境界 |
|---|---|
| **下境界** | 炼气期（一至十三层）→ 筑基期（初/中/后）→ 结丹期（初/中/后）→ 元婴期（初/中/后）→ 化神期（初/中/后） |
| **中境界** | 炼虚期（初/中/后）→ 合体期（初/中/后）→ 大乘期（原著多不分阶） |
| **上境界** | 渡劫（关口，过关即飞升仙界）→ 真仙 |

> 依据：V2C127「下境界包括了炼气、筑基、结丹、元婴、化神等五层，中境界有炼虚、合体、大乘三层，到了上境界其实只剩下渡劫这一层关口了」。

> 注：境界正名为 **炼气**（`炼气期` 原文 360 次）；`练气` 是动词（"练气打坐""培元练气"），**不作境界名**。`练气一层 / 练气十三层` 原文 0 次。
>
> **层数写法（已核）**：原著作 **「炼气期X层」**（带"期"），如「炼气期九层」V2C147、「炼气期六七层」V3C223、「炼气期四层」V3C275；顶层为十三层——V3C216「法力还突飞猛进至了十三层，到了**炼气期的顶层**」。游戏「炼气X层」缺"期"，应作「炼气期X层」。

### 天劫（V7C1219）

| 类型 | 对象 | 间隔 |
|---|---|---|
| 小天劫 | 元婴、化神 | 300 年 |
| 大天劫 | 炼虚、合体、大乘 | 3000 年 |
| 仙劫 | 飞升真仙界 | — |

关键结论：
- **丹药是硬门槛**，不是"攒够经验自动升"。
- 结丹期起，普通丹药无效，须**数百年药材 / 天地灵药**炼制。
- 化丹为婴"千难万难"，九曲灵参、补天丹是**倍增几率**而非保送。

**天人有五衰**（X2C327，24 次）：每逢大境界必历一次五衰，且「前面两衰的降临与修行时间有关」（X2C328）。

**仙界战斗力口径**（与灵界不同）：仙界比的不是法力多少，是**对法则的理解**。

所以卷一的战斗强度按灵寰界本土档设计（化神级宗门、妖修、一只天鬼），不是按真仙档。

## 五、铁律（禁止）

1. 不得跳过小境界直接跨大境界。
2. 无筑基丹不得筑基；无对应条件不得结丹 / 元婴 / 化神。
3. 不得用"经验值 / 等级 / 升级"解释修为。
4. 寿元不得超过上表。
5. 境界文案统一用「炼气」，禁用「练气」。
6. **禁止自造丹药**：`炼虚丹`、`大乘丹`、`渡劫丹` 原著 0 次，不得使用；炼虚靠「五行合一」而非吃丹。
7. 炼虚寿元"无穷"须在**灵界**；人界天地元气不足，仍有限。
8. **禁止「大乘中期 / 大乘后期」**：`大乘中期` 原著 0 次，`大乘后期` 仅 1 次。统一写「大乘期」。
9. **渡劫是关口不是层**：不得写「渡劫初期 / 渡劫中期」，只有「渡劫」或「渡劫期」。
10. **境界名不得缩写成网络语**：不写「化神期大成」「元婴满级」，原著是「化神后期」「元婴后期」。
