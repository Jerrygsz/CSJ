# 剧情动作库 / 道具库（StoryStage 演出素材）

> 真源：`js/storyStage.js` 的 `ACTS` 与 `PROPS`。本文只做索引与选型建议，改动作仍改代码。
> 所有偏移按「34px 人高」写，运行时按 `footY = y + ch/2` 与 `K = ch/34` 缩到实际精灵高度（12×14 网格，scale 1.4~1.8）。

### 溪边 —— 伤号 / 对峙专用（chuisui 那一组）

| 动作 | 画面 | 适用人物 / 场景 |
|---|---|---|
| `writhe` 毒发抽动 | 贴地几道痉挛弧 + 汗点 + 地面一线 | 厉飞雨抽髓丸发作；配合 `rot` 才是真躺下，否则像站着发抖 |
| `threaten` 刀架颈 | 横刃压到对方颈侧 + 腕上露一截 + 一线血光 | 厉飞雨「给我一个不杀你的理由」、逼问、挟持 |

> **`rot` 是演出参数不是动作**：`{t:'actor', who, rot:-1.42}` 让精灵绕脚底锚点旋转，用来演趴地 / 倒地 / 倚靠。精灵只有站姿，不转就演不出「趴在水边」。

## 三·补、地形与场调

`zones[].kind` 现支持：`house / hut / ruin / wall / gate / stair / bamboo / cliff / rope / stoneDoor / herb / stream / waterfall / pillar / stele / pine`，为室内戏、断碑、松林、太南谷与嘉元城新增以下二十类（`stele` / `pine` 与上表重叠，去重后代码里共 33 类 —— 以下表为准）：

| kind | 画面 | 用途 |
|---|---|---|
| `floor` | 暖石色渐变底 + 22×34 砖缝 | 压住战斗地图的野外表层；室内戏必须接近实色，否则远山树影会从砖缝透出来 |
| `bed` | 石台 + 一头薄被 | 石床、卧榻 |
| `rack` | 三层格架 + 一排小瓶 | 药架、书架、法器架 |
| `table` | 桌面 + 两条腿 + 桌上药碗 | 石桌（不要用 `pillar` 的椭圆，会像一摊水） |
| `lamp` | 一排小盏 + 暖黄火点 + 光晕 | 满屋灯烛，室内戏的主要光源 |
| `stele` | 石座 + 碑身 + 左上崩口 + 三道刻痕 | 断碑、墓碑、界石（`pillar` 的椭圆立在地上像一面镜子，当碑不能用） |
| `pine` | 细直干 + 三层填充针叶伞 | 松林、山道两侧。**三层针叶必须填充**，只画线会叠成栅栏；竹林才用 `bamboo`。树干只画到树冠下缘，画到顶会像旗杆 |
| `ground` | 土色实底渐变 + 固定伪随机斑驳 | 野外戏铺在别的地图上时用它压住那张图的枯树 / 山丘 / 战斗圈；`floor`/`paved` 是室内的地，不要混用 |
| `paved` | 青灰方砖 + 30px 砖缝 | 青砖广场（ch128）。与 `floor` 的暖石色一冷一暖，一眼能分出屋里屋外 |
| `mist` | 三层横向雾带，左右渐变收边 + 上下正弦起伏 | 怪坡白雾。**硬边矩形一眼就是贴上去的白纸**；只画在人物之下当背景墙，盖到人脸上就成马赛克 |
| `stall` | 挑杆 + 横杆 + 矮桌 + 摊布 + 三件小物 | 散修货摊（ch128「像小商贩一样摆起小货摊」） |
| `stonelamp` | 青铜柱 + 盏口 + 一块发光白石 + 径向光晕 | 灵石灯（ch129「盏里不放灯油，托一块拳头大的白石」），太南小会夜戏的主要光源 |
| `river` | 灰蓝实底渐变 + 疏密递增的横向波纹 | 乡鲁大运河（ch100）。水面必须接近实色，否则这张图的野外表层会从水纹缝里透出来 |
| `dock` | 木色实底 + 22px 板条（同色系微差）+ 一道细缝 + 沿板长木纹 + 靠水一侧一排木桩 | 小码头木栈（ch100「全部用简易的木板搭制」）。**相邻两行明暗交替 + 竖缝画实 = 砖墙**，人像站在墙上；板子是同一种木料顺着河岸铺，只差一点点色。栈沿那排短桩很关键，省掉就像一块铺在地毯上的木板 |
| `shed` | 两根立柱 + 草席斜顶 + 四道席纹 + 棚下一块破幔 | 码头的两座竹棚（ch100）。席纹要斜压，画成横条会看成一面墙 |
| `crate` | 实底筐身 + 敞口暗部 + 一道亮筐沿 + 编纹竖道，宽窄高矮错开、四只少一只 | 烂筐破袋（ch100「东一处西一角堆得到处是」）。只描一个椭圆边框就是水洼；等距等大摆一排又像柜台上四只碗。别用方块，方块一看就是木箱 |
| `screen` | 三扇绢面 + 两笔墨竹 | 室内折屏，用来挡住背后那片空 |
| `candle` | 白蜡身 + 黄火苗 + 一圈暖光 | 白日点着的那对白蜡烛（ch116），迷药千人醉就在蜡芯里 —— 它得显眼，白日点蜡本身就是破绽 |
| `lane` | 夯土实底渐变 + 几块手画不规则半埋石 + 墙根两道水痕 | 城中小巷地面（黑水巷 ch101）。满是方砖会冷成一块板子、纯夯土又会亮成一条空带子，两样都不行 |
| `chair` | 靠背做成「两立柱 + 一道顶档」的框 + 椅面 + 两条腿 | 让主位坐得住（严氏 ch109）。人站在椅面这个坐标上，被椅面挡掉下半身就读成坐着；靠背画成实心一块，立刻变床头柜 |

`STAGES.<id>.tone` 现支持 `indoor`（暖褐暗场 + 中心灯烛光）、`dusk`（冷蓝紫压边 + 冷白中心光，傍晚靠灵石灯照明）与 `night`（整屏先压一层冷蓝再叠暗角，午夜戏用它 —— `dusk` 那点边角压暗压不住亮土色）。**注意四条铁律**：

1. 场调只压边缘、中心留透，否则会把主画布画的主角一起吃掉；
2. 地面用实色（`floor` / `paved` / `ground`）时，必须让剧情层自己画主角（`drawHero`），同时给主画布置 `G.hideHero = true`，收场再恢复 —— 否则主角会被整块地面盖住，只剩一个淡影；
3. 改了场调配色一定要换 `toneKey` 前缀（现为 `t3:`），否则离屏画布缓存会把旧配色一直贴下去；
4. 场调必须画在「地面之后、人物之前」：地面是不透明的，画在前面会被整片盖掉（`indoor` / `dusk` 曾经一点效果都没有，就是顺序反了）。

## 四、下一批可接的场景与所需素材

按原著顺序，缺口最大的是这两段：

> 墨大夫摊牌（ch29~57）已做成 `mishi` 段；野狼帮之围（ch77）已补进厉飞雨报信与曲魂随行；厉飞雨·抽髓丸（ch20~21）已做成 `chuisui` 段；太南谷入谷（ch126~129）已做成 `wagang` + `tainan` 两段；嘉元城（ch100~118）已做成 `jiayuan` + `mofu` 两段，见上表。

1. **潇湘院毒杀（ch121~122）** —— 嘉元城这条线还差这一场：韩立扮小厮端酒菜进包房，沈三起疑、范沮让他先试吃，他吃了；退出、守在檐下等；一盅茶的功夫，屋里四个人先后笑着毒发。收场是孙二狗一夜之间做了四平帮帮主（曲魂 + 引魂钟）。
   动作：`pour`（端酒）、`drink`（试吃）、`wipe`（擦嘴）· `writhe`（笑魂散发作，配 `rot` 横躺）· `give`（交引魂钟）
   地形：需要 `brothel`（包房：`floor` + `screen` + `table` + `lamp` 已够，但酒席要一张 `banquet` 长案）
   人物：沈重山 / 钱进 / 范沮 / 沈三 / 小金芝（后四个只有几句台词，可复用现有江湖人精灵）
2. **独霸山庄 · 欧阳飞天（ch126 回述）** —— 只有一段过场：赏月、剑符削头、验首级。原著是回头补述，做成 `StoryStage` 也要注明「这是回述，不是实时」。
3. **黄枫谷 / 绿波洞日常（ch145~231）**
   核心戏：叶师叔上门以筑基丹换差事 → 百药园接差 → 灵猿夜袭 → 绿液催药。
   动作：`refine`（炼丹）· `dig`（药圃）· `guard`（同门比试）· `slash`
   道具：`cauldron`（丹炉）· `talisman`（画符）· `sword`（青元剑）

## 五、不要做的事

- 不要把动作写成「通用光圈」兜底（`drawAct` 的 else 分支只是防崩，不是演出）。
- 不要用浅灰色画刀剑：地面是米色，会直接消失。剑用 `rgba(62,78,92,.95)`，刀用深褐。
- 不要让道具挂在 `y-15` 这类绝对偏移上，必须走 `footY - n*K`，否则人物一换 scale 就飘。
- 不要给没有原著依据的人配专属道具（例如给张袖儿配剑），群众演员只给通用器物。
