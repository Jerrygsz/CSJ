# 剧情动作库 / 道具库（StoryStage 演出素材）

> 真源：`js/storyStage.js` 的 `ACTS` 与 `PROPS`。本文只做索引与选型建议，改动作仍改代码。
> 所有偏移按「34px 人高」写，运行时按 `footY = y + ch/2` 与 `K = ch/34` 缩到实际精灵高度（12×14 网格，scale 1.4~1.8）。

## 三·补、地形与场调

`zones[].kind` 现支持：`house / hut / ruin / wall / gate / stair / bamboo / cliff / rope / stoneDoor / herb / stream / waterfall / pillar / stele / pine`，为室内戏、断碑、松林与太南谷新增以下十二类：

| kind | 画面 | 用途 |
|---|---|---|
| `floor` | 暖石色渐变底 + 22×34 砖缝 | 压住战斗地图的野外表层；室内戏必须接近实色，否则远山树影会从砖缝透出来 |
| `bed` | 石台 + 一头薄被 | 石床、卧榻 |
| `rack` | 三层格架 + 一排小瓶 | 药架、书架、法器架 |
| `table` | 桌面 + 两条腿 + 桌上药碗 | 石桌（不要用 `pillar` 的椭圆，会像一摊水） |
| `lamp` | 一排小盏 + 暖黄火点 + 光晕 | 满屋灯烛，室内戏的主要光源 |
| `stele` | 石座 + 碑身 + 左上崩口 + 三道刻痕 | 断碑、墓碑、界石（`pillar` 的椭圆立在地上像一面镜子，当碑不能用） |
| `pine` | 细直干 + 三层填充针叶伞 | 松林、山道两侧。**三层针叶必须填充**，只画线会叠成栅栏；竹林才用 `bamboo`。树干只画到树冠下缘，画到顶会像旗杆 |
| `ground` | 土色实底渐变 + 固定伪随机斑驳 | 野外戏铺在别的地图上时用它压住那张图的枯树 / 山丘 / 战斗圈；`floor`/`paved` 是室内的地，不要混用 |
| `paved` | 青灰方砖 + 30px 砖缝 | 青砖广场（ch128）。与 `floor` 的暖石色一冷一暖，一眼能分出屋里屋外 |
| `mist` | 三层横向雾带，左右渐变收边 + 上下正弦起伏 | 怪坡白雾。**硬边矩形一眼就是贴上去的白纸**；只画在人物之下当背景墙，盖到人脸上就成马赛克 |
| `stall` | 挑杆 + 横杆 + 矮桌 + 摊布 + 三件小物 | 散修货摊（ch128「像小商贩一样摆起小货摊」） |
| `stonelamp` | 青铜柱 + 盏口 + 一块发光白石 + 径向光晕 | 灵石灯（ch129「盏里不放灯油，托一块拳头大的白石」），太南小会夜戏的主要光源 |

`STAGES.<id>.tone` 现支持 `indoor`（暖褐暗场 + 中心灯烛光）与 `dusk`（冷蓝紫压边 + 冷白中心光，傍晚靠灵石灯照明）。**注意三条铁律**：

1. 场调只压边缘、中心留透，否则会把主画布画的主角一起吃掉；
2. 地面用实色（`floor` / `paved` / `ground`）时，必须让剧情层自己画主角（`drawHero`），同时给主画布置 `G.hideHero = true`，收场再恢复 —— 否则主角会被整块地面盖住，只剩一个淡影；
3. 改了场调配色一定要换 `toneKey` 前缀（现为 `t3:`），否则离屏画布缓存会把旧配色一直贴下去。

## 五、不要做的事

- 不要把动作写成「通用光圈」兜底（`drawAct` 的 else 分支只是防崩，不是演出）。
- 不要用浅灰色画刀剑：地面是米色，会直接消失。剑用 `rgba(62,78,92,.95)`，刀用深褐。
- 不要让道具挂在 `y-15` 这类绝对偏移上，必须走 `footY - n*K`，否则人物一换 scale 就飘。
- 不要给没有原著依据的人配专属道具（例如给张袖儿配剑），群众演员只给通用器物。
