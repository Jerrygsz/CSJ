# 掉落分层（loot_tier）

> 管：什么来源掉什么、掉多少。防：小怪掉神装、顶级法宝烂大街、关键丹药乱出。

## 一、原著掉落逻辑

- **妖兽按阶掉落**：低阶妖兽 → 材料 / 低阶妖丹；中高阶妖兽 → 中高阶材料 / 妖丹（妖丹 277 次、内丹 96 次）。
- **修士洞府 / 古修遗骸** → 法宝 / 功法 / 丹药（机缘性，非常规刷取）。
- **秘境 / 剧情** → 定宝（虚天鼎、九曲灵参、掌天瓶级）。
- **没有"小怪爆神装"**：顶级法宝（通天灵宝，199 次）从不从普通怪身上掉。

## 四、铁律

1. **小怪不得掉**：筑基丹、法宝级以上、通天灵宝、剧情定宝。
2. **关键丹药来源固定**：筑基丹只能走剧情/炼制/特定秘境，不得野外随机。
3. **顶级法宝唯一来源**：通天灵宝、虚天鼎级只走剧情/秘境。
4. **材料按阶匹配**：低阶地图不掉中高阶材料。

## 四·2 灵界分层（V8–V12，炼虚→真仙）

灵界的掉落逻辑换了一层：**不再靠随机好货，靠「打过这一关才给」**。

| 层级 | 来源 | 可掉 | 严禁掉 |
|---|---|---|---|
| **L1 灵界小怪（炼虚）** | 黑凤族/风元大陆等 | **只掉灵物（地图 `mats` 池）**，不掉成品 | 任何人界法器/符箓（精铁短剑、粗布道袍一律不出） |
| **L2 灵界精英** | 同上 | **同样只掉灵物** | 同上 |
| L3 灵界首领（合体） | 广寒界/倚天城/黄泉地火 | 化神以上旧宝（`req ≥ 72`）+ 灵物×9 | 玄天斩灵剑（只给一次）、`req < 72` 的任何东西 |
| L4 魔界 / 小世界（合体后期） | 魔源海/小灵天/白光界 | **玄天仙藤×1**、真灵之血×2 | 玄天之宝成品 |
| L5 大乘级对手 | 斩大乘/第一大乘/魔界大劫 | 玄天仙藤、真灵之血大量 | — |
| L6 剧情定宝 | 风元大陆（玄天斩灵剑）、飞升之劫 | 玄天斩灵剑（`unique`）、仙藤 | 该图以外任何地方 |

关键锁定：

| 物品 | 唯一/主要来源 | 依据 |
|---|---|---|
| 腾龙丹 | **黑凤族领地**一次给（`unique` 级剧情丹） | V9C1364 |
| 合体丹 | **广寒界**一次给 | V10C1770 |
| 玄天斩灵剑 | **风元大陆**一次给，`unique` + `req 260` | V8C1328 |
| 玄天仙藤 | 黄泉地火首次出，之后魔界/支线陆续给，够 3 截才飞升 | V5C633 |
| 真灵之血 | 灵界全程产出，越往后给越多 | V9C1359 |

> **四条硬约束**（灵界段最容易破的）：
> 1. 玄天斩灵剑**只能给一次**（`unique`），且不能进随机池。
> 2. 260 / 330 / 420 三关要的仙藤总共 **6 截**（1+2+3），产出总量必须够且不能溢出太多，否则玩家会把多余仙藤当垃圾。
> 3. **灵界不掉「丹」**：腾龙丹、合体丹都是剧情给，出了这两张图就没有第二枚。别在随机池里加它们。
> 4. **`noDrop` 标记**：腾龙丹、合体丹已标 `noDrop: true`。不标的话，人界 82 级的 Boss 就能爆出灵界的腾龙丹——
>    等于把炼虚关的门槛提前拆了（这个 bug 一直存在到 `20261027m` 才补上）。

## 五、游戏现状对照（`[游戏]`）

- 现游戏：Boss 死亡 = 8+ 件 tier-2 随机成品 + 5+ 材料 + 34 灵石，再叠加地图固定 `reward`。
- 需校准：
  - 34 灵石量级 ≈ 3–4 张中阶灵符（见 `economy.md`），作为 Boss 奖励是否偏高/偏低。
  - "8+ 件随机成品"是否会让**法宝级**物品从普通 Boss 掉出 → 须按 T3 规则限制。
  - 随机池是否混入 `unique / craftOnly / teach` 类（筑基丹、青元剑诀等）→ **必须排除**。

### 五·2 灵界段的实际掉落（`20261027n` 已按 arc 分段 + 上下限）

| 项 | 现状 | 判断 |
|---|---|---|
| 灵界小怪 / 精英 | **只掉灵物**（走地图 `mats` 池），0 成品 | ✅ 按 arc 分段后生效 |
| 灵界首领成品池下限 | 跟着地图修为段走：黑凤族 72 → 广寒界 90 → 倚天城 140 → 小灵天之后封顶 160 | ✅ 越深入越高 | 
| 灵界首领成品池上限 | 地图 `startLevel + 40`，不会让炼虚修士在第二张图捡到大乘器物 | ✅ `20261027n` 补 |
| 灵界本地产出 | 五件（五龙铡 150 / 血晶摩诃剑 200 / 万森法盘 220 / 擎天巨舟 260 / 鲲鹏舍利 260），全部 `rarity 4` 可随机 | ✅ `20261027n` 补，池子不再只有 8 种人界旧宝 |
| 人界（arc A–H） | 门槛 0，池子与从前完全一致 | ✅ 老玩法不受影响 |
| 腾龙丹 / 合体丹 | 各一次，且已标 `noDrop`，任何怪都不爆 | ✅ 补掉了「人界 Boss 爆灵界破境丹」的老漏洞 |
| 真灵之血产出 | 18 张图都给，累计远超 260/330/420 的需求（3+4+5=12） | ⚠️ 偏多，仙藤才是真瓶颈 |
| 玄天仙藤产出 | 7 张图给，累计约 9 截（需求 6 截） | ✅ 略有余量，合理 |
| 玄天斩灵剑 | 仅风元大陆一次，`unique` 不进随机池 | ✅ 合规矩 |

**实现要点**（改这块前先读）：

| 机制 | 位置 | 说明 |
|---|---|---|
| `inLingjie()` | `game.js` | 按地图 `arc ∈ {I,J,K,L}` 判定，不看等级（等级会被 `startLevel` 夹逼，不可靠） |
| `lootMinReq()` | `game.js` | 灵界 = `min(160, max(72, startLevel-60))`；人界 0 |
| `maxReq` | `items.js` | 灵界 = `startLevel + 40`，防止越级爆装 |
| `dropLoot(tier)` | `game.js` | 灵界 `tier < 2` → 直接掉灵物；`tier ≥ 2` → 走成品池 |
| `Items.roll(tier, boost, {minReq, hardMinReq})` | `items.js` | 有门槛时**只许往上借档**，绝不降回低阶 |
| `noDrop: true` | `items.js` 条目上 | 破境丹专用，随机池永久排除 |

### 五·3 稀有度档位（`RARITY`）

| 档 | 名 | 颜色 | 进随机池 | 典型物品 |
|---|---|---|---|---|
| 0 | 凡品 | 灰白 | ✅ | 止血丹、精铁短剑 |
| 1 | 良品 | 绿 | ✅ | 罗烟步·法诀 |
| 2 | 上品 | 蓝 | ✅ | 火弹术·法诀、软猬甲 |
| 3 | 珍品 | 紫 | ✅ | 天火液、定灵丹 |
| 4 | 至宝 | 金 | ✅ | 筑基丹、玄龟甲、腾龙丹 |
| **5** | **仙品** | **青白** | **❌ 只走剧情** | 玄天斩灵剑、金罡灭魔神雷、忘情诀、逆灵真阴大法 |

> `20261027l` 补的第 6 档。此前 `RARITY` 只有 0–4，而玄天斩灵剑用了 5，通关结算时 `RARITY[5].color` 会抛异常（`renderVictoryLoot`）。
> **仙品不进随机池**是刻意的：`rollRarity` 封顶 4，所以玄天之宝一类只能靠剧情/破境固定给——正合原著「玄天之宝不落凡手」。

### 五·4·b 斩仙（arc L，420，前传终章，`20261027t`）

| 项 | 规则 |
|---|---|
| 随机成品 | 仍走灵界档公式（`req ≥ 160`），**这是待办**：420 段的首领理论上该只掉真仙级器物 |
| 固定战利品 | 万灵血玺 / 魔光 / 火须子三件仙品（`unique` + `noDrop`，只走通关奖励） |
| 强度 | `diff 5.0`、Boss 血量 300000——**前传血量最高的 Boss**，高于飞升之劫（240000） |

> **待办**：420 段（zhenxian / zhanxian / huimoyuan / daoguo / renzu / fsjie）随机池下限仍是 160，
> 想抬高就得先补够 360 以上的可掉成品，否则池会空、只剩材料掉。
> 正确顺序是「先补成品、再抬门槛」，反过来做会把这一段的掉落清空。

### 五·5 仙界档（arc M，后传，20261027s）

| 项 | 规则 |
|---|---|
| 仙界小怪 / 精英（tier<2） | **只掉灵物**（仙元石、玄黄之气），不掉成品 |
| 仙界首领（tier≥2） | 成品门槛 `req ≥ 420`（真仙级往上），上限 `startLevel + 40`（卷一即 460） |
| 一次性宝物 | 玄黄之索 / 天外飞豆标 `noDrop`，只走剧情奖励 |
| 判定 | 按 `arc === 'M'`，不看等级（等级会被 `startLevel` 夹逼） |

> **为什么要单开一档**：灵寰界是「低档世界」，韩立带伤藏拙，
> 地上躺一把人界法器是硬伤——但也不能让灵寰界的土产混进仙界档。
> 所以仙界档与灵界档一样：**小怪只掉灵物，成品只由首领出**。
